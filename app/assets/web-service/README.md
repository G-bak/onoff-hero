각 개별 사진 페이지의 `Free to use under the Unsplash License` 표시를 확인했다. [Unsplash License](https://unsplash.com/license)에 따라 웹사이트 설명용 사진으로 사용하며, 사진 자체를 재판매하거나 이미지 제공 서비스를 만들지 않는다. 작가와 원본 링크를 푸터에서 제공한다. 제휴·추천 관계를 주장하지 않는다.

이미지는 앱 자산으로 import하여 해시 URL로 제공한다. 방문자의 화면에서 Unsplash에 사진을 직접 요청하지 않는다. 첫 사진만 우선 로드하고, 제작 과정 사진은 지연 로드한다.
