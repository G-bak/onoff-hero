# MARKETING — 카드 입체감 보강

2026-09-12. 사용자가 승인한 채널 콘텐츠·제목·인물·스크롤 길이를 유지하면서 펼침 중 입체감을 보강했다. 로컬만 반영했다.

## 레퍼런스와 차이

[FOLLOW.ART 제작사 프로젝트](https://videinfra.com/work/follow-art)의 공개 시연 영상 중 TESTIMONIALS 카드 장면을 재검토했다. 보관된 관찰 자료는 `outputs/research/2026-09-09/follow-art/video8-sheet.jpg`, 원본 조사 이력은 [TITLE-MOTION-v3.md](../v2/TITLE-MOTION-v3.md)다. 현재 본사이트는 실제 브라우저에서 Cloudflare 확인 화면으로 막혀 있어 현재 라이브 스크롤을 직접 확인한 것으로 설명하지 않는다.

넓은 곡면의 명암, 비스듬한 면의 원근, 카드 사이의 깊이 차이가 입체감을 만드는 점을 참고했다. 여기서는 기존 감쇠 스프링과 세 채널의 서로 다른 높이를 유지하고, 완성된 화면에서도 완만한 곡면과 기울기를 유지한다. 가운데 긴 블로그는 완만하게 두고, 양옆은 펼침 후반에 곡률을 반전시켜 오목하게 만든다. 곡률 축도 좌우 반대 방향으로 기울여 옆으로 비껴 접히는 느낌을 준다. 직전 버전의 완성 후 평면 복원은 최신 사용자 피드백으로 제거했다. 레퍼런스의 V자 접힘·지면 구도·자산·코드를 복제하지 않는다.

## 구현

- `lib/marketing-surface.ts`: 원본 버텍스를 면 안에서 기울어진 축으로 옮긴 뒤 원통형의 넓은 곡률과 작은 대각 비틀림을 계산하고 원래 축으로 되돌린다. 축에 투영된 지면 폭으로 반지름을 구해 대각 모서리가 과도하게 꺾이지 않게 한다. 앞면과 몸체에 같은 변형을 적용해 두께를 유지하며 UV는 바꾸지 않는다. 매번 원본 좌표에서 계산하므로 반복 진입에도 변형이 누적되지 않는다. 완성 후 곡면은 유지하며 비틀림만 0이다.
- `lib/card-showcase.ts`: 카드별 기존 스프링 위에 앞뒤 이동·기울기·곡률의 짧은 호흡을 더했다. 최종 곡률은 인스타그램 −0.78, 블로그 0.24, 포스터 −0.84이며 모바일은 78%로 완화한다. 초반 양의 곡률에서 펼침 26% 이후 연속적으로 반전한다. 곡률 축은 +0.24/0/−0.24rad로 좌우 대칭이며 지면 전체 회전과 별개다. 세 장 모두 서로 다른 작은 yaw/pitch/roll을 유지한다. 최종 x=−2.7/0/+2.7, 공통 z=0과 기존 카드 비율은 그대로다. 펼침 도중 카메라가 최대 1.4 월드 단위 후퇴해 긴 블로그의 잘림을 막는다.
- `app/components/card-showcase.tsx`: 분할된 앞면과 몸체, MeshStandardMaterial의 조명 반응으로 입체감을 표현한다. 앞면의 원본 지오메트리를 z=0.045로 이동한 뒤 변형해 몸체와 교차하며 줄무늬가 생기던 현상을 막았다. 변형과 조명은 기존 프레임 루프 안에서 처리하며 종료 시 기존 자원 정리를 따른다.
- 채널 이름은 펼침 후반부터 표시해 초반 깊이 묶음에서 서로 겹치지 않는다. 제목의 첫 1.67초 등장 후 고정, 마케터 8포즈/4.89초 반복, 로딩·오류 대체·모션 정지 정책은 유지한다.

## 검증

71개 테스트를 포함한 `npm run ci:build` 통과. 곡면 두께와 UV 보존, 반복 변형 후 원본 복원, 여러 화면 비율·포인터 위치의 전체 펼침 구간에서 실제 곡면의 카메라 투영 경계를 검사한다. 최종 곡면의 중간 지점과 앞뒤를 함께 투영해 카드 간 겹침도 확인한다. 브라우저는 9개 크기, 휠 진입/재진입, 제목 고정, 숨김, 모션 정지, WebGL 복구, 자산 지연 중 로더, JS 없는 화면을 확인했고 오류는 없었다.
