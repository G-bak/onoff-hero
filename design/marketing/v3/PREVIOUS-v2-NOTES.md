이전 v2 작업 당시의 보관 기록이며 현재 구현은 [v3 안내](README.md)와 [PAGE5-NOTES.md](../../../docs/pages/PAGE5-NOTES.md)를 따른다. 2026-09-12 당시 사용자 요청. 로컬 http://localhost:5187/#card 에 적용하며 커밋·push·배포하지 않는다. 이전 피드 두 장/쇼츠 영상 버전은 [보관 기록](../HISTORY-v1.md)이다.

## 현재 구성

분홍 #C5939D 배경, 검정 #090A0F, Montserrat 700 큰 제목, Pretendard 본문을 유지한다. MARKETING의 아홉 글자가 세로로 압축된 상태에서 크게 뻗고, 수축과 반동이 옆 글자로 이어진다. 글자당1.15초,65ms 차이이며 이후 작은 세로 파동이 이어진다. opacity는1이다. 이전 rotateX 등장 효과는 제거했다. [FOLLOW.ART 영상 조사·최신 모션](../v2/TITLE-MOTION-v3.md)을 따른다. 앞쪽 WEB 면이 제목을 드러내는 순간부터 시작하며 역스크롤 이탈 후 재진입하면 다시 시작한다. 정지/숨김/움직임 감소를 따른다.

카드는 왼쪽 **인스타그램**, 가운데 **블로그**, 오른쪽 **광고 포스터**다. 온결 보습크림 광고, 루움의 이불 선택 가이드, 모닝오븐 점심 세트 광고를 새로 생성했다. 콘텐츠 문구·타깃 가설·조사 출처·정확한 ImageGen 프롬프트는 [v2 자료](../v2/README.md)에 보관한다. 모두 가상 브랜드 시안이며 실제 고객 실적이 아니다.

본문은 **홍보할 시간 없다면 / 온앤오프에 맡기세요**다. 운영 부담과 대행 서비스를 직접 표현한다. 인스타그램/블로그 머리말·아래 설명은 로컬 Pretendard 준비 후 canvas에 그린다. 포스터는4:5 원본 비율이고 나머지 두 장은 플랫폼 설명을 포함한720:1034 비율이다. 이전 쇼츠 비디오·VideoTexture 실행 코드는 제거했다.

## 좌표와 스크롤

얇은 평면 광고판이 깊이 방향의 묶음에서 좌우로 펼쳐진다. 최종 중심 x는−2.7/0/+2.7, z는모두0이며 높이와 기준선이 같다. 중간 카드를 앞으로 크게 돌출시켰던 원근 차이를 없앴다. 작은 시차·상승·회전으로 펼친 뒤에는 약한 부유만 남긴다. 펼침 자체의 출발 묶음은 의도된 겹침이며 완성된 세 장은 분리되어야 한다. 카메라 투영된 실제 중심에 플랫폼 이름을 맞춘다.

펼침 완료 시점은 진행률0.68에서0.60으로 앞당겼고, 초기 시간 제한은1.15초에서0.82초, 추종 계수는8에서12로 바꿨다. 추가 감상 스크롤은 데스크탑45vw→30vw, 모바일80svh→50svh이다. 전체 높이를 단순히 자르지 않고 실제 section 높이−stage 높이를 진행률 계산에 사용한다. 1440×900에서는전체1548→1332px, 추가구간648→432px이다. WEB→MARKETING 면 전환의 기존0.8 비율은 그대로다.

## 인물 보존

기존8포즈의 위치·크기·얼굴·RGB·팔 동작·순서는 보존했다. ImageGen 분리 마스크는 원본과 정합 오차가 있어 그대로 쓰지 않고, 원본 신발 앞코·뒤꿈치·밑창을 기준으로 발 아래 alpha만 보정했다. 최초 runtime WebP의 RGB를 가져와 무손실 WebP로 저장하므로 재압축으로 인물 색상이 달라지지 않는다. y<278의 보이는 RGBA 변경0, 남은 인물의 보이는 RGB 변경0을 생성 스크립트가 검사한다.
