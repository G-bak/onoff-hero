# MARKETING v3 — 실제 채널 화면과 설치 장면

2026-09-12 후속 사용자 수정. 첫 제목 등장 효과는 승인됐으며, 반복 파동은 삭제했다. 세 장을 같은 광고 이미지로 구성했던 v2를 채널별로 다시 만들었다. 로컬만 적용하며 실제 게시·설치·고객 성과가 아닌 가상 캠페인이다.

## 조사 → 적용

- [Meta 공식 Instagram 피드 설명](https://about.fb.com/news/2022/03/two-new-ways-to-control-your-instagram-feed/)과 본문의 [공식 UI 이미지](https://about.fb.com/wp-content/uploads/2022/03/01_Feed-View.png?resize=890%2C890)를 실제 브라우저에서 열어 계정/사진/반응 조작 구조를 확인했다. 2022년 공식 예시이며 2026년 앱의 모든 UI를 픽셀 단위로 재현했다고 주장하지 않는다. 이번 광고 시안은 게시물 헤더, 계정과 광고 표시, 4:5 사진, 더 알아보기, 좋아요/댓글/공유/저장, 캡션/해시태그/댓글 예시로 구성했다.
- [NAVER 게시글 설정 안내](https://help.naver.com/service/5593/contents/15408?lang=ko&osType=COMMONOS)를 실제 브라우저에서 확인했다. 본문과 공개 범위, 댓글, 공감 등 게시글의 구조를 참조했다. 루움의 블로그는 제목/작성자/날짜/커버/도입/소재·보온감·세탁 세 소제목과 본문/구매 전 체크리스트/마무리/공감·댓글로 이어지는 긴 기사다. 플랫폼 기능의 완전한 복제나 실제 발행 화면이 아니다.
- [오프린트미 창업 인쇄물 가이드](https://www.ohprint.me/blog/startup-printing-guide)의 매장 입구 홍보물과 문/벽의 신메뉴 포스터 활용 설명을 확인했다. 이를 모닝오븐 점심 메뉴의 실제 사용 맥락으로 해석해 빵집 입구 나무 A형 입간판에 인쇄된 광고를 새로 생성했다. 가상의 설치 예시이며 실제 시공 사진으로 소개하지 않는다.
- 제목 참고 영상과 직접 관찰 구간은 [FOLLOW.ART 제작사 시연 조사](../v2/TITLE-MOTION-v3.md). 실제 본사이트는 Cloudflare 확인 화면이어서 제작사 공개 영상을 분석했다. 이번 후속 요구가 우선하므로 첫 압축/신장/반동만 보존하고 반복 운동은 제거했다.

직접 쓴 캠페인 문구는 `lib/marketing-content.ts`가 관리한다. 좋아요/공감 수, 댓글, 작성일은 시안용 예시다. 하단 가상 브랜드 표기와 접근성 설명에 이 사실을 보존한다. 제품 효능·매출·순위·고객 실적을 보장하지 않는다.

## 새 이미지 생성

이미지 생성 스킬과 Sites 자산 담당 지시에 따라 단일 자산 담당이 **내장 ImageGen 편집 1회**로 포스터 설치 장면만 생성했다. 다른 이미지는 재생성하지 않았다. 1차 포스터 PNG를 참조했으며 설치된 포스터와 현실 공간을 함께 생성한 합성이다.

- 영구 입력: `sources/poster-installed.png` — 1122×1402 / 2,541,813B.
- 참조: `../v2/sources/poster.png`.
- [도구에 전달한 정확한 전체 프롬프트](morning-oven-installed-poster.prompt.txt).
- [모드·원본 출력 경로·SHA256](morning-oven-installed-poster.metadata.json).
- [생성 후 육안 검토](morning-oven-installed-poster.review.md).
- 실행: `app/assets/marketing/poster-installed.webp` — 848×1060 / 231,146B.
- 재현: `node scripts/prepare-marketing-channels.mjs`; [해시 기록](assets.json).

주요 한국어 문구, 나무 프레임, 문/유리 반사, 실내 빵 진열, 보도 접촉 그림자를 직접 확인했다. 원본 포스터와 픽셀 단위로 동일하지 않으며 인쇄 면은 요청보다 작게 나온 결과를 채택했다. 기존 v2 포스터 소스/실행 파일은 이력으로 보존하되 페이지 런타임은 새 설치 장면을 사용한다.

인스타그램/블로그 UI는 글자 정확성과 유지보수를 위해 생성형 이미지에 맡기지 않고 `lib/marketing-textures.ts`가 코드로 그린다. 생성 사진 2장은 기존 v2를 재사용한다. Pretendard 전체 필요 문자와 Montserrat, 사진, 인물 디코딩이 준비된 뒤 canvas에 그린다. 720×1420 게시물과 720×1720 기사이므로 중앙 블로그가 더 길다. WebGL 손실 시 같은 2D canvas로 전환하고 JS/자산 실패 때는 같은 콘텐츠 데이터의 HTML을 제공한다.

## 움직임과 초기 화면

카드별 짧은 시차 뒤 감쇠 스프링 응답으로 가속→약 8% 초과 이동→반동→정착한다. 서로 다른 높이/깊이/기울기 경로를 사용한다. 후속 요청으로 펼침 도중 얕은 곡면과 조명, 추가 깊이, 짧은 카메라 후퇴를 더했다. 최신 후속 요청으로 완성 후에도 카드별 곡면과 기울기를 유지한다. 긴 블로그는 완만하게, 양옆은 펼침 후반 곡률이 반전하며 좌우로 비껴 휘어진 상태다. 카메라만 원래 거리로 돌아온다. [입체 모션 관찰·구현·검증](DEPTH-MOTION.md)을 따른다. 이전 V자 종이 접힘은 사용하지 않는다. 최종 x는 −2.7/0/+2.7, z는 모두 0이며 카메라는 가로 폭과 긴 블로그 높이를 함께 맞춘다. 채널 이름은 각 카드의 투영된 하단을 따라 배치한다. 제목은 글자당 1.15초, 간격 65ms로 총 1.67초 뒤 고정한다.

첫 HTML은 `data-renderer=pending`이며 SYSTEM과 같은 준비 화면 정책을 따른다. loading 동안 제목/사진/인물을 가리고, 실제 첫 WebGL 프레임 후 표시한다. 제목/인물/카드의 등장 시간은 준비 완료와 앞쪽 WEB 면의 가림 해제 뒤부터 흐른다. 12초 제한 또는 자산/WebGL 오류는 읽을 수 있는 기본 화면으로 전환한다. JS 없는 화면은 noscript로 로더 대신 본문을 표시한다. 역스크롤 재진입, 탭 숨김, 모션 정지, 움직임 감소를 보존한다.

마케터의 8포즈/4.89초 반복/외형/위치와 스크롤 길이는 유지했다. 현재 QA 결과와 로컬 주소는 [PAGE5-NOTES.md](../../../docs/pages/PAGE5-NOTES.md)에 기록한다.
