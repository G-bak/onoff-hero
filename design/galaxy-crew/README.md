# 2페이지 팀 제스처 — 1회 재생

2026-09-12 후속 수정. 현재 버전은 v3/이며, v2/와 이전 8포즈 자료는 보존한다. 로컬에만 적용했고 커밋·push·배포하지 않았다.

## 이미지와 동작

기존 다섯 직무 캐릭터의 뒤돌기 8포즈씩, 총 40개 이미지를 새로 생성했다. 정면 → 고개와 어깨의 선행 → 한 발 들기와 무릎 굽힘 → 측면에서 발 디딤 → 반대발 따라 딛기와 뒷모습 정착 순서다. 팔의 반대 방향 움직임과 옷·머리의 자세 변화도 이미지에 포함한다. 기존 v2의 08–15번 팔 올리기 이미지는 그대로 연결해 인물별 총 16포즈를 사용한다. 모든 사람이 같은 시간표를 사용한다. 실제 직원 사진이 아닌 기존의 가상 직무 미니어처다.

[사용자가 제공한 미디어오늘 기사](https://www.mediatoday.co.kr/news/articleView.html?idxno=121889)의 원피스 뒷모습 제스처를 참고했다. 후속 사용자 요청에 따라 왼손목/아래팔의 검은 X를 새 이미지에 생성했다. 의상과 인물은 기존 회사 캐릭터다. 기사 이미지를 사이트에서 요청하지 않는다.

최종 포즈는 파란 재킷의 오른손 허리 자세, 흰 셔츠의 옆으로 기울인 팔·골반, 남색 카디건의 내려놓은 오른팔, 회색 셔츠의 넓은 발 간격·오른팔 굽힘, 검정 재킷의 오른손 주머니 자세로 차이를 준다. 들고 있는 손은 모두 왼손이다.

## 원본과 정렬

- v3/pose-sheets/: 선택한 뒤돌기 PNG 5장, 각각 1536×1024, 4열×2행
- v3/prompts/: 생성과 실제 수정 프롬프트
- v3/SOURCE-INSPECTION.md, source-manifest.json: 원본 검수와 생성 출처
- v3/frames/: 새 뒤돌기 40장과 기존 팔 올리기 40장, 각각 240×320
- v3/source-layout.json, animation.json: 배치·추출 경계·끝점 정렬·원본 및 유지 프레임 해시·재생 시간

일부 최초 생성의 팔 방향은 실제 이미지 편집으로 수정했다. 현재 프레임에는 좌우반전이나 CSS 회전을 적용하지 않는다. 손과 X도 CSS/SVG로 덧그린 장식이 아니라 생성 이미지의 일부다.

녹색 배경을 제거한 뒤 scripts/crew-sheet.mjs가 연결된 인물 실루엣을 추출한다. 명목상 행 경계를 살짝 넘은 주먹도 같은 인물의 픽셀로 보존한다. 정수 격자로 자르면서 손을 잃는 방식은 쓰지 않는다. 새 뒤돌기는 정면·뒷면 두 끝점의 정수리와 받침대 하단만 기준으로 크기를 보정하고 중간 크기 보정값을 보간한다. 각 중간 포즈의 키를 강제로 통일하지 않아 무릎을 굽히며 몸이 낮아지는 움직임을 보존한다. 받침대 하단 중앙은 고정한다. 기존 팔 올리기 PNG는 바이트 단위로 유지하며 SHA-256을 기록한다.

## 재생·성능·재생성

lib/galaxy-crew.ts의 순서는 0부터 15까지 한 방향이다. 뒤돌기 0–7번은 각각 180·90·100·70·110·100·80·70ms, 8–10번은 각70ms, 11–14번은 각90ms로 약1.37초 후 최종 자세에 도달한다. 발 들기·체중 이동·착지에 다른 간격을 주고 정면 대기는180ms로 유지한다. 그 뒤에는 프레임을 반복하거나 정면으로 돌아가지 않는다.

- 웹: app/assets/galaxy-crew/crew-sprite.webp, 3840×1600, 852,290바이트. 부모의 --crew-pose-x 하나가 다섯 행을 동시에 표시한다.
- GIF: design/archive/public/images/galaxy-crew/team-salute.gif, 912×320, 16프레임, 885,180바이트. loop=1이며 마지막 프레임의 저장 지연은2000ms다. 디코더는 한 번 재생한 뒤 마지막 프레임을 유지한다.
- 아틀라스 디코딩·인물 등장 완료와 인물 영역의 실제 가시성을 확인한 후 재생한다. 긴 모바일 화면 위쪽에서 동작이 미리 끝나지 않는다.
- HOME에서 전체 은하 진입을 다시 시작할 때 인물 동작을 초기화한다. MARKETING에서 돌아오면 최종 뒷모습을 유지하며 인물만 따로 재생하지 않는다. 모바일의 인물 가시성은10%/55% 경계로 판단하고 영역 이탈은 정지만 하며 초기화하지 않는다.
- 탭 숨김과 MOTION OFF는 현재 자세에서 일시 정지한다. 움직임 감소 설정은 최종 뒷모습이다. 이미지 디코딩 실패 시 기존 정면 캐릭터를 유지한다.
- 은하 공통 시간은 1.4배로 빨라졌지만 인물의1.37초는 실제 시간으로 유지한다. 별도 상시 프레임 루프나 개별 GIF 다섯 개를 추가하지 않았다.

재생성 명령: npm run prepare:galaxy-crew. 원본·프레임·자산은 관리 대상이며 서버 시작 때마다 재생성하지 않는다. 1페이지 인물 아틀라스는 변경하지 않았다.

생성기가 새40개 실루엣·정렬 시 손/몸 잘림·유지40프레임의 크기와 해시·GIF16프레임·모든 지연·1회 반복 설정을 검사한다. 최종 CI와 브라우저 결과는 PAGE2-NOTES.md 및 outputs/qa/2026-09-12/system/crew-step-*에 기록한다. 브라우저에서는 전체16포즈의 동기화, 뒷모습 유지, 양방향 스크롤 재진입, 숨긴 탭 정지, 모바일 진입 시점, 움직임 감소를 검사한다.
