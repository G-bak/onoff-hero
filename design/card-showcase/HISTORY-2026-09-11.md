## 장면과 동작

- 분홍 `#C5939D` 배경, 화면 폭을 채우는 검은 `THE CARD`, 그 위로 휘어진 두 개의 긴 화면이 겹친다. 새 페이지는 기존 1·2페이지와 같은 앞면 걷기 전환 뒤에 나온다.
- 제목은 로컬 Montserrat Black 900의 외곽선에서 세로획을 길게 늘이고 가로획은 얇게 남긴 자체 SVG다. 글자별 길이가 다르며 진입 시 세로 비율이 늘어난다. 기존 첫 화면의 글꼴·제목은 그대로다.
- 현재 이미지는 후속 사용자 요청에 따른 작은 잡지 변형이다. 왼쪽은 주황색 ON&OFF JOURNAL 표지, 오른쪽은 검정·아이보리·파랑의 인물 화보 지면이다. 내장 이미지 생성 도구로 새로 만든 가상 시안이며 실제 고객 실적이나 실제 발행 잡지로 표시하지 않는다. 이전 패스·포트폴리오 이미지는 원본과 함께 보존했다.
- 새 디자인 요소는 화면 상단의 작은 `ON&OFF JOURNAL / VOL. 01 / 2026` 한 줄이다. 분홍 배경, 큰 타이틀의 기존 굵기·위치, 두 곡면의 크기·좌표·곡률·카메라·스크롤·포인터 동작, 메뉴를 유지한다. 사용자는 전체 재디자인을 원하지 않았으며, 요청했다가 취소한 타이틀 굵기를 다시 적용하지 않는다.
- 서로 다른 반지름의 원통 곡면에 세로 방향으로 감긴 실제 메시다. 평면 이미지의 CSS 기울기나 반복 GIF로 대체하지 않는다. 카드의 휘어지는 각도와 위쪽 이동은 스크롤에 연결되며 역스크롤 시 같은 모습으로 돌아온다.
- 포인터는 카메라 시점을 작은 원호 위에서 움직인다. 부드럽게 목표에 도달한 뒤 프레임 예약을 멈춘다. 자동 무한 회전은 원본 장면과 달라 추가하지 않았다.
- 장면 실행은 메뉴의 CARD 활성 표시와 분리했다. 2페이지가 걷히기 시작하는 순간부터 곡면을 그려, 전환 도중 평면 대체 이미지가 곡면으로 갑자기 바뀌지 않게 한다. 2페이지로 완전히 돌아오면 다시 쉰다.
- 화면 비율이 달라도 진입 자세를 유지하고 캔버스가 카드 위아래를 자르지 않도록 카메라 확대율을 조정했다. 모바일은 제목을 두 줄로 재구성하고 같은 두 곡면을 사용한다.
- 우측 공통 메뉴는 HOME·WHY·CARD다. 후속 수정 요청으로 메뉴 전체의 분홍 배경·그림자 박스를 삭제했다. 글자와 얇은 트랙에만 분홍 외곽선을 두어 큰 검은 제목·카드 위에서도 읽히며, 콘텐츠는 그대로 보인다. 3페이지 활성 막대는 브랜드 파랑 `#343CFF`, 현재 항목은 굵은 검정이다. 세 링크 바깥의 단일 트랙·단일 막대를 재사용하고 스크롤 진행률과 120ms 보간을 유지한다. 상담 버튼과 창은 기존 공통 기능을 재사용한다.

## 코드·자산 관리

- `app/components/card-showcase.tsx`: 제목, Three.js 장면, 관찰자·프레임 제어·GPU 해제·기본 이미지.
- `app/card-showcase.css`: 분홍 화면, 제목과 캔버스, 모바일, 공통 메뉴의 해당 페이지 테마.
- `lib/card-showcase.ts`: 곡면 좌표와 스크롤 자세의 순수 함수. 각도·기울기·곡률 설정도 여기서 관리한다.
- `app/assets/card-showcase/`: 현재 `cover-editorial.webp`, `feature-editorial.webp`, `title.json`. 기존 `pass.webp`·`portfolio.webp`는 보존하지만 앱에서 가져오지 않는다.
- `design/card-showcase/`: 이전 생성 PNG 원본, 사용자 스크린샷, 이전 프롬프트. `editorial/`에는 현재 두 PNG와 [잡지 변형 생성 프롬프트](editorial/generation.prompt.md)가 있다.
- 재생성: `node scripts/prepare-card-showcase.mjs`. 현재 두 장 모두 780×1560, WebP quality 88 / effort 6. 표지 77,008 bytes, 화보 87,852 bytes, 합계 164,860 bytes. 동일한 출력은 다시 쓰지 않아 불필요한 개발 캐시 갱신을 막는다. 웹에서는 PNG 원본·참고 영상·스크린샷·이전 두 WebP를 요청하지 않는다.
- `lib/site-sections.ts`가 메뉴·타입·앵커를 공유한다. DESIGN 잔여 ID나 스타일을 다시 추가하지 않는다.
