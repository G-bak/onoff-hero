# DESIGN 고객 목적별 포트폴리오 — 2026-09-12

3페이지의 추상적인 그래픽 시안을 고객이 실제로 발주하는 디자인 결과물로 교체했다. 카페·베이커리, 뷰티 D2C, 온라인 리빙 브랜드를 **우선 고객 가설**로 삼았다. 이는 국내 제작사 사례와 ON&OFF의 통합 서비스를 바탕으로 정한 초기 방향이며, ON&OFF의 고객 분석 자료로 검증한 타깃은 아니다.

## 조사와 문구

아래 국내 서비스·포트폴리오 페이지를 읽고, 구매에 필요한 상품 정보와 일관된 브랜드 표현을 중심으로 구성했다. 해당 사이트의 이미지를 복제하거나 실제 고객 실적으로 사용하지 않았다.

- [머니콘텐츠 서비스](https://moneycontents.co.kr/page/service.html): 브랜드 출시, 패키지, 상품 촬영, 상세페이지, 광고를 연결한다. 단독 그래픽보다 실제 판매 접점에 적용된 작업물을 보여주는 방향에 참고했다. 과거 가격·성과 수치는 사용하지 않았다.
- [메이커리 패키지 포트폴리오](https://www.makerystudio.co.kr/projects-package): 베이커리·커피·뷰티·생활용품 등 업종별 패키지 사례를 확인했다. 업종에 따라 다른 소재·색·제품 표현이 필요하다는 작업 가설에 참고했다.
- [카페24 PRO 상품 콘텐츠](https://global.cafe24.com/start/productcontent.html): 상품의 가치 전달과 구매 판단에 필요한 정보, 썸네일·상세페이지의 연결을 강조한다. 알아보기 쉬운 상품 사진과 사용 장면·소재 디테일을 함께 보여주는 방향을 확인했다.
- [STUDIO-L 제작 패키지](https://www.studio-l.kr/packages/): 촬영·상세페이지 구성·최종 이미지·웹 제작의 결합을 확인했다. 이미지가 실제 납품물의 역할을 갖도록 하는 기준에 참고했다.

새 메인 문구는 **눈길을 사로잡고 / 구매로 이어지게**다. 고객의 관심과 구매라는 목적을 짧게 전달하도록 직접 작성했다. 조사한 회사의 문구를 그대로 옮긴 것이 아니며, 수치나 성과 보장을 붙이지 않았다. 영문 보조 문구는 `DESIGN THAT SELLS`다.

## 세 작업물

| 우선 대상 / 목적 | 가상 브랜드 | 보여주는 디자인 결과물 |
| --- | --- | --- |
| 카페·베이커리 / 메뉴 기억과 매장 방문 | 모닝오븐 · MORNING OVEN | 소금빵 사진과 붉은 메뉴 포스터, 같은 심벌을 사용한 봉투·커피컵 |
| 뷰티 D2C / 제품 신뢰와 제형 전달 | 온결 · ONGYEOL | 크림 용기·박스, 캠페인 타이포그래피, 제형 콘텐츠 |
| 온라인 침구·리빙 / 사용 장면과 촉감 전달 | 루움 · RUUM | 침실 라이프스타일 이미지, 원단 디테일 카드, 제품 띠지 패키지 |

실제 납품 고객이 아닌 자체 콘셉트 작업이다. 화면의 `CONCEPT PORTFOLIO`와 `가상 브랜드 디자인 시안` 표기로 구분한다. 세 이미지의 방향·팔레트는 서로 다르지만, 기존에 승인된 종이색 편집 지면과 인쇄 전환을 유지한다.

## 생성 원본과 실행 자산

내장 `image_gen`을 사용해 이미지별 한 번씩, 세 번의 호출을 한 병렬 배치로 생성했다. 세 원본을 모두 시각 검토한 뒤 720×900 WebP로 내보냈다. 별도 변형·재시도 생성은 없다. 실제 원본 크기는 요청 크기와 다른 1122×1402 RGB PNG이며, 앱에서는 불투명 4:5 작업물로 사용한다.

| 이미지 | 원본 | 실행 WebP | 전송 크기 |
| --- | --- | --- | --- |
| 모닝오븐 | [bakery.png](sources/bakery.png) | [design-bakery.webp](../../../app/assets/design-showcase/design-bakery.webp) | 106,922B |
| 온결 | [beauty.png](sources/beauty.png) | [design-beauty.webp](../../../app/assets/design-showcase/design-beauty.webp) | 56,992B |
| 루움 | [living.png](sources/living.png) | [design-living.webp](../../../app/assets/design-showcase/design-living.webp) | 103,906B |

합계 **267,820B**. 원본과 전송본의 SHA-256은 [assets.json](assets.json), 정확히 제출한 전체 프롬프트는 [PROMPTS.json](PROMPTS.json), 원본 생성 경로와 시각 검토는 [GENERATION-REVIEW.md](GENERATION-REVIEW.md)에 보존했다. 생성 검토 문서는 저장소 밖에서 자산을 준비한 당시의 기록이다. 현재는 이 폴더에 원본을 보관하고 앱에 연결했다.

생성 결과에서 베이커리 배경의 작은 영어 간판과 리빙 보조 카드의 직사각 비율이 프롬프트와 다르다. 핵심 한글 문구·브랜드·납품물 구성은 검토했고, 원본을 편집해 사실처럼 보정하지 않았다. 브라우저의 실제 축소 화면에서도 확인했다.

```powershell
node scripts/prepare-design-assets.mjs
```

현재 v2를 기본으로 내보낸다. 대표 이미지·인쇄 구획·썸네일은 같은 Vite 해시 URL을 공유한다. 이전 추상 시안은 [상위 기록](../README.md)에 보존하며 `--legacy` 옵션으로만 재생성한다.

## 등장과 스크롤

DESIGN 인물의 별도 투명도 진입 애니메이션을 없애고, 앞면이 넘어가며 3페이지가 드러날 때부터 실제 춤 포즈를 재생한다. 앞면 전환 중 인물만 움직일 수 있으며 뒤 페이지의 입력 잠금은 유지한다. 초기 로더의 `main.inert`, 탭 숨김, 가려진 페이지, MOTION OFF와 움직임 감소 정책은 보존한다. 기존 인물 이미지와 1120ms 춤 시간표는 변경하지 않았다.

추가 감상 스크롤은 150svh에서 100svh로 줄였다. 1440×900에서 전체 DESIGN 높이는 2,250px에서 1,800px로 20% 줄고, 추가 감상 구간은 1,350px에서 900px로 줄었다. 이미지 세 장을 선택하는 목차와 NEXT는 계속 사용할 수 있다. 페이지 전체 종횡비나 휠 입력을 고정하지 않는다.
