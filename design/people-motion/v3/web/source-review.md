# WEB source03 — 빈 칠판 + 필기 경로 검토

- 원본: web-sheet-03.png, 실제 1536 × 1024 RGB PNG, 4열 × 3행.
- 정확한 프롬프트: prompt03.txt.
- 내장 image_gen 1회 생성. 참조는 web-sheet-01.png의 구도/인물과 승인된 website.png였다. 손 중복이 있던 source02는 참조하지 않았다.
- 모든 글자를 미리 그리지 않고, 빈 칠판 앞에서 손으로 사각형·헤더·내용 경로를 움직이는 방식으로 변경했다.
- 원본 그대로 저장했으며 배경 제거·선 제거·정렬·보간·합성은 하지 않았다.

## 관찰 결과

인물의 단발·안경·네이비 카디건·가느다란 비율·원형 받침대가 유지됐다. 칠판·카메라·발·오른팔은 시각적으로 안정적이다. 기존 왼팔로 필기하며 각 포즈에 두 팔과 두 손만 보이고 source02의 중복 손 문제는 사라졌다. 몸의 정면 회전이나 스텝도 없다.

핵심 경로는 좌상 → 우상 → 우하 → 좌하 → 좌상 순서로 분명하게 형성됐다. 이전의 정지된 완성 글자 옆에서 손만 움직이는 문제가 없으며, 실제 손 끝을 측정해 선을 합성하는 후보로 검토할 수 있다.

## 반드시 알릴 부족한 점

1. 모든 칠판이 완전히 비어 있지는 않다. Pose1(첫 행 두 번째)의 보드 상단에 흰 가로선이 남았다. 전체 시트 좌표로 대략 x484..591, y54이며, 셀 내부로는 x100..207, y54이다. 이는 요청하지 않은 생성 흔적이다. 나머지 열한 판에는 글자·도형·선이 보이지 않는다.
2. 목표 좌표가 정확히 지켜지지는 않았다. 사각형 위/아래 변이 약간 기울고, 마지막 A 복귀도 첫 A와 3~5px 정도 차이가 있다.
3. 헤더 E→F의 두 팁 높이는 대략 y87→73이므로 꽤 기울어 있다. 목표였던 y98의 수평선이 아니다.
4. 내용 G→H는 대략 y115→110으로 조금 기운다. 같은 높이로 합성하려면 손끝과 선의 접촉 여부를 다시 확인해야 한다.
5. 긴 왼쪽 도달 동작(Pose1·4·5·6)은 다른 포즈보다 팔을 훨씬 펴며 특히 Pose6은 목표 x125보다 더 왼쪽 x105 부근까지 간다. 큰 몸 회전이나 발 이동은 없지만, 최종 재생에서 팔 길이/속도가 자연스러운지 확인해야 한다.
6. 배경 좌상단은 RGB(18,240,26)으로 순수 #00FF00이 아니다.
