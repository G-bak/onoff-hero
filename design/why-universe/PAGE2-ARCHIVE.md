# 2페이지 — 다른 감각, 하나의 방향

> 폐기된 매듭·지휘자 연출의 보관 이력이다. 현재 SYSTEM 은하·인물은 [은하 기획](../galaxy/ART-DIRECTION.md)과 [인물 기준](../galaxy-crew/README.md)을 따른다. 과거 생성 명령으로 현재 구현을 대체하지 않는다.

2026-09-11 최신 정면·측면 로고 시안에 맞춰 검은 유광 튜브가 만들어진 뒤 정면으로 돌아오는 연출을 구현했다. 후속 제공된 `cosmic-knot.zip`의 3D 코드와 장면을 확인하고 반사 환경·내부 조명·감쇠 모션 기법을 적용했다. [로컬 WHY](http://localhost:5187/#why), [최신 시안·연출 계획](KNOT-MOTION.md), [참고 기술 적용 기록](COSMIC-STUDY.md). 로컬 작업이며 커밋·push·배포하지 않았다. [이전 조사](ART-DIRECTION.md)는 디자인 과정의 기록이다.

## 현재 디자인

- 다섯 개의 둥근 고리가 앞뒤로 연결되는 검은 유광 공간 매듭이다. 최신 정면·측면 시안의 곡률, 굵기, 정면 각도를 기준으로 실제 3D 튜브를 구성했다. 이전 리본·평면 심볼과 가는 발광선 도입은 제거했다.
- 흰색과 보라색 반사를 가진 검은 유광 재질이다. 로컬 생성한 연속 반사 띠·소프트박스 환경을 PMREM으로 만들고 물리 기반 금속·클리어코트에 사용한다. 로고 내부의 중심 1개·고리 5개 조명과 바깥 2개 조명을 로고 재질에서만 계산해 매듭 안쪽의 깊이를 드러낸다. 별·배경의 기존 조명은 유지하며 외부 HDR·모델·시안 이미지를 런타임에서 다운로드하지 않는다.
- 주변 3개 경로는 깊이와 작은 비대칭 굴곡을 가진다. 경로 위로 밝은 신호와 잔광이 흐르고 9개의 입체 별이 앞뒤를 통과한다. 반복 별은 한 InstancedMesh로 그린다.
- 전체 캔버스에 어두운 네이비 배경과 미세한 구름·입자를 그린다. 데스크톱에는 높은 밝기에만 약한 블룸과 MSAA를 적용하며 작은 화면은 직접 렌더링한다. 제목 뒤는 어둡게 유지한다.
- 문구는 **다른 감각, / 하나의 방향.**, **기획부터 실행까지, 하나로 연결합니다.**다. 제목의 두 줄은 결합 순간부터 시차를 두고 펼쳐지며 서비스 노드·설명·인물이 뒤따른다. 텍스트는 로컬 Pretendard와 HTML이다.
- 인물은 직전 버전에서 생성한 은색 재킷의 8포즈·2.62초 루프를 그대로 사용한다. 새 장면의 지휘자 방향과 맞아 추가 이미지 생성이 필요하지 않았다. 원본과 해상도는 유지한다.
- 프레임 너비 100%, 데스크톱 높이 `max(100svh, 740px)`. 1100px 이하는 세로 구성·최소 900px, 700px 이하는 최소 850px이다. 500px 이하의 설명은 제목 아래에 배치한다. 페이지 전체의 종횡비를 고정하지 않는다.
- 기존 1페이지, 3페이지 잡지 변형, 면 전환, 공통 HOME/WHY/CARD 메뉴와 상담톡을 보존한다.

- 0.25–3.45초: 세로 측면 자세를 유지하며 검은 튜브가 양쪽으로 길어진다. 실제 메시의 표시 범위와 두 개의 둥근 끝단으로 구성한다.
- 3.65–6.05초: 닫힌 매듭이 완성된 뒤 정면으로 돌아오고 조금 앞으로 이동한다. 이후 약 ±7도 안의 느린 회전·작은 부유로 연결한다. 2.1초부터 제목, 5.6초부터 설명·인물·라벨이 드러난다.
- 4.6–8.4초: 주변 경로가 펼쳐지고 9개 별의 순환으로 연결된다. 전체 도입은 약 8.6초다. 각도 변화와 순환 전환의 시작·끝 속도를 연결해 갑작스러운 방향 전환을 피한다.
- 공통 frame loop의 하나의 시간축으로 카메라·형상·셰이더를 제어한다. HOME 시작으로 완전히 돌아오면 다시 시작하고, 작은 역스크롤이나 CARD 왕복은 기존 시점을 이어간다.
- 렌더러는 처음 보일 때 준비하며, 입장 시간은 첫 페이지 전환 58% 이후와 초기 main inert 해제를 기다린다. 숨긴 탭·화면 밖·가려진 장면은 프레임을 예약하지 않는다. 처음부터 OFF이거나 움직임 감소이면 완성된 정지 장면을 표시한다.
- 컨텍스트 손실 시 SVG 대체 화면을 표시한다. 복원할 때 GPU 환경 맵과 후처리 버퍼를 포함한 엔진을 재생성하고 시간축은 보존한다. JS 미사용도 같은 HTML/SVG와 첫 인물 포즈를 보여준다.
- 형상은 초기화 때만 만들고 매 프레임은 uniform·행렬을 갱신한다. 데스크톱 렌더 버퍼는 165만 픽셀 이내, 1100px 이하는 DPR 최대 1.2·입자 260개·블룸 제외다. 입자는 한 배치로 그린다.

### 사선으로 빠지는 그래픽한 면 전환 — 2026-09-10

### 하이라이트 애니메이션

- 1페이지가 완전히 걷히면 `서비스의 수` 배경이 왼쪽에서 오른쪽으로 먼저 그어지고, `연결의 방향.`의 네온 붓 터치 두 겹이 뒤따른다. 배경은 100ms 후 480ms 동안, 붓 터치는 각각 380ms/460ms 후 620ms/580ms 동안 재생해 약 1초에 끝난다.
- 원래 글자·강조색·위치·완료 상태의 비율은 유지한다. 배경 크기와 `clip-path`만 애니메이션하며 붓 이미지 자체를 가로로 늘이거나 텍스트를 움직이지 않는다. 추가 이미지·라이브러리·반복 타이머를 사용하지 않는다.
- 기존 전환의 `is-why-revealed` 클래스가 재생을 제어한다. 전환 끝 부근의 작은 역방향 스크롤에서는 유지하고, 전환 진행률이 0으로 돌아온 뒤 다시 진입하면 재생한다. 이벤트 정리 시 클래스도 제거한다.
- 초기 로더가 main의 `inert`를 해제한 이후에만 재생해 `#why` 직접 진입에서도 효과를 볼 수 있다. 움직임 감소 설정 또는 JavaScript 미사용 시 강조를 즉시 완성 상태로 표시한다.
- 로컬 Chrome에서 PC·모바일의 실제 중간 프레임, 완료 후 정지, 작은 역스크롤 유지, HOME 왕복 재생, 상담창 닫기, 직접 WHY 진입, 움직임 감소 및 JavaScript 미사용을 확인했다. 제목 폭과 가로 넘침도 검사했다.
