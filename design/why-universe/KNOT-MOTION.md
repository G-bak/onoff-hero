# Signature knot — upright construction to frontal reveal

> 폐기된 매듭·지휘자 연출의 보관 이력이다. 현재 SYSTEM 은하·인물은 [은하 기획](../galaxy/ART-DIRECTION.md)과 [인물 기준](../galaxy-crew/README.md)을 따른다. 과거 생성 명령으로 현재 구현을 대체하지 않는다.

2026-09-11. 최신 시안 [정면](knot-front-reference.png)과 [측면](knot-side-reference.png)에 맞춰 중앙 로고를 검은 유광 튜브·흰색과 보라색 반사의 공간 매듭으로 구현했다. 별도 이미지 생성 없이 실제 Three.js 형상과 애니메이션을 사용한다. 이전 174713 시안과 가는 발광선 도입은 최신 연출 기준이 아니다.

## 최종 연출

- 0.25–3.45초: 세로로 세운 측면 자세에서 검은 튜브 자체가 두 방향으로 길어진다. 실제 메시의 연속된 구간과 둥근 양 끝을 사용한다. 가는 발광선·진입 빛점·유령 윤곽선은 제거했다.
- 3.45–3.65초: 완성된 닫힌 매듭을 짧게 유지한다.
- 3.65–6.05초: 완성 뒤에만 정면 회전과 작은 앞쪽 이동을 시작한다. 시작과 끝의 속도가 0인 곡선으로 연결한다.
- 2.1–3.85초: HTML 제목의 두 줄이 같은 시간축 안에서 시차를 두고 드러난다.
- 4.6–8.4초: 주변 3개 경로가 중심에서 펼쳐진다. 각 9가닥의 빛과 잔광, 총 9개의 입체 별이 같은 좌표와 진행률을 공유한다.
- 정면 도착 이후: 약 ±7도 안의 느린 회전과 작은 부유가 정지 속도에서 자연스럽게 이어진다. 약 8.6초에 전체 구성이 완성된다.

첫 페이지 전환이 58%에 도달하기 전에는 입장 시간축을 멈춘다. GPU는 첫 여백이 보일 때 준비하되, 뒤쪽에서 도입부를 소진하지 않는다. HOME 시작으로 복귀하면 재생을 초기화하고 CARD 왕복에서는 시점을 유지한다.

최신 속도 조정은 튜브 생성 구간만 3.8초에서 3.2초로 줄이고 이후 순서를 0.6초 앞당겼다. 정면 회전의 2.4초 길이는 유지한다. 생성 중에는 로고 X/Z 기울임·상위 그룹 흔들림·카메라 시차를 0으로 두고, Y -90도에 로고 위치에서 카메라를 향하는 시선 각도를 보정한다. 화면 오른쪽에 있는 로고도 정확한 측면으로 보이며 정면 회전이 시작되면 이 보정을 부드럽게 해제한다. 인물과 바닥 그림자는 함께 오른쪽으로 프레임 너비의 4% 이동했다(데스크톱 left 20%, 1100px 이하 16%).

## 조형과 재질

앞뒤로 교차하는 닫힌 (2,5) 공간 곡선을 직접 구성했다. 640개의 길이 구간과 24개 단면 구간, 반지름 0.195의 튜브다. 위치·접선·법선이 폐곡선 이음부에서 이어진다. 후속 `cosmic-knot.zip`의 3D 기법을 참고해 중심 반지름·굴곡 비율, 연속된 수평 반사 띠, 낮은 거칠기의 금속과 클리어코트, 안쪽 6개·바깥 2개 조명을 적용했다. 로고 재질에서만 자체 조명을 물리 기반 BRDF로 계산하고 별과 배경의 조명은 보존한다. `onBeforeCompile` 확장에 별도의 프로그램 캐시 키를 사용한다. [기술 참고·적용 기록](COSMIC-STUDY.md).

둥근 양 끝과 점진적으로 늘어나는 실제 삼각형 범위로 입체가 만들어진다. 완성되기 전에는 정면 회전이 시작되지 않는다. PNG 시안은 런타임에서 불러오지 않는다.

## 유지보수 기준

- 시간표·곡선 수학: `lib/why-universe.ts`
- 공간 형상·궤도 묶음: `lib/why-universe-geometry.ts`
- 재질·조명·그리기·정리: `lib/why-universe-scene.ts`
- 로고 전용 반사 환경·내부 광원: `lib/why-signature-studio.ts`
- 신호·잔광: `lib/why-universe-shaders.ts`
- 재생·가시성·복구: `app/components/why-universe.tsx`

컨텍스트 손실 상태에서 이전 GPU 자원을 정리하고, 복구 알림 후 새 환경 맵과 엔진을 생성한다. 이미 복원된 새 컨텍스트에서 이전 핸들을 삭제하지 않는다. 숨긴 탭·가려진 페이지에서는 정지하며, 움직임 감소와 처음부터 OFF인 경우 완성된 장면을 제공한다. 데스크톱 버퍼 165만 픽셀, 작은 화면 90만 픽셀 상한을 유지한다.

구현 확인에 사용한 공식 자료: [Material](https://threejs.org/docs/pages/Material.html), [TubeGeometry](https://threejs.org/docs/pages/TubeGeometry.html). 설치된 Three.js의 `WebGLProgram`, `Material`, `TubeGeometry` 구현도 확인했다.

검증 결과·녹화는 [PAGE2-NOTES.md](../../docs/pages/PAGE2-NOTES.md)에 기록한다. 배경·문구·인물·주변 구성과 1·3페이지는 유지한다. 로컬 검수 작업이며 커밋·push·배포하지 않았다.
