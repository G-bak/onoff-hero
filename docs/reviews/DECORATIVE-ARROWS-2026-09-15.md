# 전체 장식 대각선 화살표 제거 — 2026-09-15

사용자가 전체 페이지의 링크가 아닌 장식용 대각선 위 화살표를 모두 없애도록 요청했다. 직전 상세 효과 영역만 제거하던 범위를 홈과 상세 전체로 넓혔다.

## 변경 범위

| 위치 | 제거 내용 |
| --- | --- |
| HOME | 3D 팀 카드의 Canvas 화살표와 정적 대체 카드의 동일 장식 |
| SYSTEM | 인물 아래 `분야별 전문가 / 한 팀에서 끝까지` 옆 화살표 |
| DESIGN·WEB | 큰 영문 제목 옆 화살표 |
| SERVICES | 다섯 콜라주의 영문 단어 옆과 `ALL IN ONE` 원형 도장 안 화살표 |
| 서비스 상세 5개 | 큰 영문 표지 옆 화살표와 공통 문의 영역 배경 화살표 |
| 기획 상세 | `PLAN / TO DO` 도장과 작업 예시 카드의 화살표 |
| 공통 상세 과정 | 마지막 카드의 대각선 화살표. 운영의 완료 체크는 유지 |
| 웹 상세 | 제작 유형별 포함 작업 목록의 화살표 표시 |

요소 제거에 맞춰 전용 위치·크기·반응형 스타일도 정리했다. 제목·본문·이미지·카드 크기·앵커·모션은 유지한다. 실제 서비스 이동, 문의, 참고 자료, 이메일 링크와 건너뛰기·다음 예시·재시도·문의 확인 같은 동작 버튼의 아이콘은 유지한다. 단계 사이를 잇는 가로 화살표도 유지한다. MARKETING·TOGETHER·문의 화면에는 제거 대상인 독립 대각선 장식이 없다.

직전 [운영 상세 작업 범위 탭·완료 체크와 효과 화살표 제거](../pages/SERVICE-DETAILS-NOTES.md)를 보존한다. 이번 변경은 로컬 전용이며 커밋·push·배포하지 않는다.

## 검증

- `npm run ci:build`: 기존 테스트143개·린트·타입·빌드·CSS/공개 자산 검사 통과.
- 홈·상세5개·문의의7개 경로에서 HTTP200을 확인했다. 서버 HTML의 대각선 문자·화살표 SVG를 검사했고, 남은 항목은 모두 링크 또는 실제 동작 버튼 안에 있다. 제거한 장식 클래스는 없다.
- 서버 HTML에서 상세 표지 글자와 운영 상세 탭2개·완료 아이콘1개가 유지됨을 확인했다. CSS 의사 요소와 HOME Canvas는 소스 변경으로 별도 확인했다.
- 실제 브라우저의 시각·클릭·3D 재생 검수는 이번에 수행하지 않았다.
