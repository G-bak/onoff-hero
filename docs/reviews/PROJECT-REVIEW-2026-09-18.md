## 검증 범위

배포 전 기본 DNS를 사용한 `npm run check:seo -- https://on-onf.com`이 통과했다. 공개7페이지의 HTTP·SEO, robots/sitemap,404, www 이동, 문의 API와 검색봇 User-Agent 응답을 검사했다. 실제 검색 색인 결과는 측정하지 않는다.

앱 소스가 기존 성공 빌드와 같으므로 문서만을 위해 로컬 전체 빌드를 반복하지 않는다. 문서 링크·공개 자산 목록과 `git diff --check`를 확인하고, 이번 main push가 실행하는 전체 검사·프로덕션 빌드의 성공 및 운영 버전을 별도로 확인한다. 원본 근거는 Git 제외 `outputs/qa/2026-09-18/project-publish/`에 둔다.

이번 작업의 범위는 소스 검토·자동 검사·HTTP/서버 HTML/자산 확인이다. 실제 브라우저 화면·클릭·드래그 검수와 문의 전송은 수행하지 않는다. 로컬 서버와 DNS·PC 설정은 유지한다.
