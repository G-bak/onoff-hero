# HOME 오프닝 브라우저 검증 — 2026-09-13

이 문서는 최초 5.2초 연출의 브라우저 수정 이력이다. 이후 사용자 요청으로 변경한 8.7초 탄성 연출·Ease Out·TOGETHER 문의 안내의 최신 검증은 [추가 QA](OPENING-AND-INQUIRY-2026-09-13.md)를 따른다.

사용자가 실제 브라우저 검증을 요청한 뒤, 기존 `http://localhost:5187` Node/Vite 서버에서 Chromium으로 수행했다. [구현 기록](../pages/HOME-OPENING-NOTES.md)의 후속 검증이다. 모바일은 브라우저 화면 크기 및 터치·DPR 2 에뮬레이션이며 실제 iPhone/Android 하드웨어나 Safari 검증은 아니다.

## 발견하고 수정한 문제

1. **헤더와 건너뛰기 중첩**: 메인 헤더가 나타나는 4.5초에도 건너뛰기 버튼이 같은 위치에 남았다. 배경과 함께 흐려지고 도킹 완료 후 숨기도록 수정했다. Escape는 연출 종료까지 유지한다. 마지막 PC/모바일 캡처에서 헤더 opacity 약 0.45–0.48일 때 건너뛰기는 `visibility:hidden`이다.
2. **홈 복귀 후 초기 GPU 오류 안내 누락**: resume 분기는 로더를 생략하지만 초기 카드 실패가 runtime ready를 유지해 재시도 안내도 사라졌다. 실제 WebGL context 생성을 차단해 재현했다. 실패는 runtime fallback으로 기록하고 로더가 닫힌 뒤만 복구 안내를 표시하도록 분리했다. 초기 진입 오류는 기존 로더가 안내하며, 복귀 오류는 기본 카드와 `3D 다시 시도`를 제공한다. 두 경로 모두 차단 해제 후 실제 카드 복구를 확인하고 회귀 테스트 2개를 추가했다.
3. **상세 → 서비스 목록 오위치**: 새 문서의 `/services/web`에서 `/#services`로 이동하면 6032px 목표 대신 1032px에 멈췄다. 라우터가 해시를 읽을 때 자식 SectionEntry의 좌표가 부모 sticky 배치 이전 값이었다. layout effect에서 준비하고 모든 조상 배치 이후 microtask로 한 번 다시 계산하여 라우터의 스크롤 작업 전에 앵커를 완성한다. 강제 scrollTo나 라우터/배포 설정 변경은 추가하지 않았다. 실제 목록 복귀와 뒤로/앞으로 저장 위치 복원을 재검증했다.
4. **짧은 모바일 문의 버튼 중첩**: 375×667에서 긴 문의 버튼이 본문을 가렸다. HOME의 너비 700px 이하·높이 760px 이하에 한해 기존 다른 섹션과 같은 아이콘 표시를 적용하고 하단 24px로 옮겼다. 접근성 이름과 링크는 유지하며, 390×844에서는 기존 글자 버튼을 유지한다.
5. **Three.js 그림자 경고**: 설치 버전에서 제거된 PCFSoftShadowMap 대신 지원되는 PCFShadowMap을 사용했다. 최종 정상 PC/모바일 재생 구간의 pageerror·warning·error 수집 결과는 0건이다. 의도적으로 GPU를 차단한 검사의 오류는 별도로 구분했다.

모든 정상 완료 상태에서 임시 오프닝 DOM이 사라지고 `main.inert=false`, scrollY=0, 기존 카드 canvas 2개, 카드의 추가 translate 해제를 확인했다. 연결 중 카드 앞·뒤의 translate도 동일했다(PC 예: −456.358px/−456.358px).

탭 전환은 이 자동화 Chromium에서 다른 탭을 전면에 둬도 `document.hidden=false`였다. 따라서 실제 OS 탭 숨김을 검증했다고 하지 않는다. 별도로 브라우저의 hidden 값과 visibilitychange를 제어해 도킹 후 4.034초에서 700ms 동안 시간이 그대로 멈추고 복귀 후 UI·잠금 해제가 완료됨을 확인했다. 기존 순수 프레임·컴포넌트 검사도 숨김/복귀를 검증한다.

## 최종 글자 위치 비교

실제 페이지 글꼴이 준비된 상태에서 같은 DOM 측정을 사용해 3D의 정착 프레임을 별도로 그렸다. HTML 워드마크와 3D 렌더를 각각 캡처하고 글자 영역 픽셀의 R/G 값 150 미만 마스크를 비교했다. 비교용 배경·가림 스타일은 검증 페이지에만 적용하고 제거했다.

| 화면 | HTML 글자 외곽 x/y | 3D 글자 외곽 x/y | 마스크 IoU |
| --- | --- | --- | --- |
| 1440×1000 | x=89–1360, y=226–449 | x=89–1359, y=226–449 | 0.99144 |
| 390×844 | x=19–362, y=240–300 | x=19–362, y=240–300 | 0.97232 |

PC의 외곽 차이는 최대 1px, 모바일의 전체 경계는 일치했다. DOM 글꼴 힌팅과 WebGL 안티앨리어싱이 다르므로 픽셀 전체가 동일하다는 의미는 아니다. 실제 최종 연결은 짧은 교차 표시로 처리한다.
