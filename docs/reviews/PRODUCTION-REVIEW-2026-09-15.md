# 운영 전체 점검·흰 배경 파비콘

기준일: 2026-09-15. 사용자가 접속 복구와 광고 테스트 성공을 알린 뒤 전체 점검과 흰 배경 파비콘 변경을 요청했다. 운영 주소는 https://on-onf.com 이다.

## 수정

- 기존 로고 생성 코드에서 파비콘의 정사각형 전체를 `#ffffff`로 합성했다.32·64px PNG는 이전 이미지에 흰색만 합성한 결과와 픽셀 단위로 일치한다. 투명 채널을 제거했고 로고 원본·홈페이지 헤더 이미지 파일은 그대로 유지했다.
- 기본 `/favicon.ico`에도 같은 로고의 흰 배경16·32·48·64px 프레임을 넣었다. 공통 메타데이터의 PNG·ICO·shortcut 주소를 `v=white-20260915`로 갱신했다.
- 생성기에서 리사이즈·여백을 만든 뒤 별도 파이프라인으로 흰색을 합성한다. 먼저 합성하면 바깥 여백이 다시 투명해지는 문제를 검수 중 발견하고 수정했다. 최종 PNG2개·ICO4개 프레임의 크기·흰색·불투명을 확인했다.
- 이전 Search Console 안내의 옛 네임서버를 새 계정 값으로 정정한 기록도 반영한다.

## 별도 계정에서 확인할 항목

1. **Google Ads 문의 완료 전환:** 사용자 제공 기본 태그 `AW-18383031274`는 설치돼 있고 사용자도 광고 테스트 성공을 확인했다. 현재 코드에는 문의 성공에 연결된 conversion 이벤트·전환 라벨이 없다. 문의 완료 전환을 집계하려면 Google Ads에서 해당 전환 액션의 설정·라벨을 확인한 뒤 서버 접수 성공 시점에 연결해야 한다. 광고 계정의 URL 기반·코드 없는 별도 설정 유무는 확인하지 않았다. [Google 공식 전환 안내](https://support.google.com/google-ads/answer/12718882?hl=en).
2. **네이버 소유 확인·수집 요청:** 운영의 NAVER_SITE_VERIFICATION 값과 HTML 인증 태그가 없다. 코드의 인증 연결 기능은 준비돼 있다. 실제 네이버 계정 등록 여부는 확인하지 않았으므로 미등록으로 단정하지 않는다. [네이버 등록 절차](../seo/NAVER-SEARCH-ADVISOR.md).
3. **Search Console 사이트맵 성공 상태:** 사이트맵200 XML·7개 정식 주소는 확인했다. Google 인증 TXT도 새 zone에 존재한다. 사용자의 사이트 접속 복구와 Search Console의 사이트맵 처리·색인 성공은 별개이며 실제 계정에서 상태 확인이 남는다. [Search Console 안내](../seo/GOOGLE-SEARCH-CONSOLE.md).

Google 검색의 파비콘은 별도 재수집 후 바뀔 수 있으며 즉시 표시를 보장하지 않는다.64px 정사각형 PNG는 Google의 현재 권장 크기(48px보다 크게)에 맞는다. [Google 파비콘 안내](https://developers.google.com/search/docs/appearance/favicon-in-search).
