## 확인 범위

구조 이동 직전 관리 대상 815개를 목록화하고 크기·SHA-256을 기록했다. 의존성·Git 내부·빌드·캐시·로컬 출력은 제품 파일 검토 범위에서 제외하되 설치 버전·검사 설정·생성 흐름은 별도로 확인했다. 앱의 라우트·컴포넌트와 lib 런타임, 공통 UI의 브라우저 API 사용 지점, CSS 모션·가시성 규칙, 타입·린트 설정, 생성·배포 스크립트를 검토했다. 코드, 문서, 자산 검토는 병행했다.

기존 Markdown 67개를 검토했고 새 색인·실행 안내·보관 안내·이 보고서를 포함해 현재 71개다. 바이너리는 사용처·크기·해시·관련 메타데이터를 확인했다. 이미지 475개를 새로 육안 검수했다는 의미는 아니다. 전체 바이너리 475개(이동 30개 포함)의 크기와 SHA-256이 보존됐다. 주요 디자인·마케팅·인물·영상의 원본/실행 파일은 기록된 해시·크기와 14개 묶음으로 대조했다.
