# 탄성 오프닝·TOGETHER 문의 안내 — 2026-09-13

최신 `&` 낙하: 사용자가 3차 Ease In을 선택한 뒤 `&` 속도만 높이도록 요청해 낙하를0.72→0.48초(1.5배속)로 압축했다. ampDrop은3.24→3.60 장면초, impact는4.32 장면초다. 실제 시작을0.24초 늦춰 착지·둥근 반동·다른 글자의 충격·정렬과 전체5.8초 연결을 보존했다. 초기에는 천천히 출발해 착지할수록 빨라지는 곡선은 같다. PC 브라우저의 낙하 중간3개 시점과 메인 연결, 오프닝·로더 테스트13개 통과를 확인했다. 로컬만 저장했으며 커밋·push·배포하지 않았다.

최신 둥근 도약: 사용자 요청으로 뾰족하고 급한 도약을 코사인 기반의 둥근 곡선으로 바꿨다. 상승·정점·착지 및 지연된 회전의 끝점 속도를0으로 만들고 가로 이동은 완만한 Ease In Out으로 조정했다. 첫 두 도약의 가로 반동은1.8%→0.8%로 줄여 후반에만 적용했다. 전체5.8초·글자별 입장 순서·정렬·메인 연결은 유지한다. PC1440×900·모바일390×844 실제 재생에서 오프닝 완료 후 scrollY=0, 카드 canvas2개, main.inert=false, 가로 넘침 없음, 콘솔 경고·오류0건을 확인했다. 관련37개 테스트·린트·TypeScript 통과이며 기존 도약 검사에 착지 직전 수직·회전 속도 확인을 추가했다. 화면은 `outputs/qa/2026-09-13/opening-elastic/rounded-*.png`에 기록했다. 아래 이징 설명은 조정 이력이고 현재 기준은 [HOME 구현 기록](../pages/HOME-OPENING-NOTES.md)이다. 로컬만 반영했다.

최신 말풍선 위치: 처음 오른쪽24px 이동 후 더 오른쪽·위로 이동해 달라는 요청으로 PC right0, 버튼 간격48px로 조정했다. 이어 너무 높다는 요청으로12px 내려 최종 간격은36px다. 모바일 right8px, 간격34px(높이700px 이하는30px), 꼬리 right12px이며 내부 여백을 줄여 본문과의 간격을 보존한다. 문의 버튼은 기존 위치다. 오른쪽 끝은 PC에서 버튼 오른쪽과 같고 모바일에서는8px 안쪽이다. Chromium PC·모바일에서 화면 밖 잘림이 없고 최종 PC 간격36px를 확인했다. 로컬만 저장했고 커밋·push·배포하지 않았다.

최신 개별 이징 조정: 약 5.8초 전체 길이를 유지하며 각 도약의 준비 압축·뒤로 당김, 비대칭 상승/낙하, 회전 지연, 큰 두 도약의 작은 가로 초과 이동 후 정착을 추가했다. 기존 대칭 가로 곡선·포물선과 동일 위상의 회전에서 각각 다른 곡선으로 바꿨다. `&`의 낙하는 3차 가속, 도킹·카드·본문은 `cubic-bezier(.16,1,.3,1)`이다. 아래 4차 Ease Out 설명은 이전 구현 기록이며 현재 기준은 [HOME 구현 기록](../pages/HOME-OPENING-NOTES.md)이다. 최신 속도 조정: 후속 사용자 요청으로 `openingPlaybackRate=1.5`를 공통 장면 시계에 적용해 전체 오프닝을 약 5.8초로 단축했다. 아래 8.7초 기록은 탄성 연출 최초 구현 당시의 시간이다. 현재 실제 시간표는 [HOME 구현 기록](../pages/HOME-OPENING-NOTES.md)을 따른다. 글자·낙하·정렬·도킹·카드·본문을 같은 비율로 가속하며 자산 준비·오류 제한과 TOGETHER 안내 시간은 기존대로다. PC 1440×1000·모바일 390×844 Chromium 재생에서 약 5.82초로 측정됐고 오프닝 종료 후 카드 canvas 2개·정상 HOME 연결과 콘솔 오류·경고 0건을 확인했다. 관련 37개 테스트·린트·TypeScript 검사를 통과했다. 로컬만 저장하며 커밋·push·배포하지 않았다.

사용자 후속 요청: 글자가 날아오는 느낌을 줄이고 천천히 통통 튀게 만들기, 로고·카드 연결을 Ease Out으로 변경하기, 마지막 TOGETHER까지 본 방문자에게 구체적인 한국어 말풍선으로 프로젝트 문의를 안내하기. 기존 저장소에 로컬 반영했다.

## 연출 변경

오프닝은 5.2초에서 8.7초로 늘렸다. 글자마다 큰 도약에서 시작해 높이·이동 거리·착지 압축이 작아지는 네 번의 도약을 적용했다. 착지 중 가로 이동을 잠시 멈추고, 압축은 글자 하단을 기준으로 보여준다. 화면 가장자리 바로 바깥에서 출발하며 깊이 이동과 회전을 줄였다. 안쪽에 도착할 글자가 먼저 들어와 뒤따르는 글자를 추월하는 겹침을 줄였다.

`&`는 3.24초에 낙하를 시작해 4.32초에 착지하고 큰 반동 뒤 작은 반동을 보인다. 5.34초에 여섯 글자의 위치·기울기·크기를 중립 상태로 정렬하고 0.32초 동안 유지한다. 로고는 5.66–7.16초, 카드는 6.42–8.40초에 4차 Ease Out으로 이동한다. 이동 시간 절반에 약 93.75%를 진행하고 남은 거리에서 길게 감속한다. 전체 시간표와 자원·접근성 정책은 [HOME 구현 기록](../pages/HOME-OPENING-NOTES.md)을 따른다.

## 문의 문구와 표시 조건

> 사업만 해도 바쁜데, 홍보까지 혼자 하시나요?

> 홈페이지·디자인·마케팅, 필요한 작업부터 골라보세요.

사용자가 맡길 수 있는 작업과 문의 페이지의 실제 서비스 선택 행동을 직접 안내한다. [가비아CNS 홈페이지 제작](https://homepage.gabiacns.com/), [디파이닝 문의](https://defining.kr/contact), [CREATIP 문의](https://www.creatip.co.kr/contact)의 구체적인 서비스·프로젝트 문의 방식을 검토해 방향을 정했다. 위 문구는 ON&OFF용으로 작성했으며 경쟁사 성과·가격·보장·무료 상담 조건을 가져오지 않았다.

`BrandFilm`의 실제 표시 준비 신호와 공통 `useSceneActivity`의 가시성을 함께 사용한다. TOGETHER가 보이고 영상 첫 프레임 또는 정적 대체 화면이 준비된 상태를 2.2초 유지하면 안내를 시작한다. 영상 재생 완료를 기다리는 기능은 아니다. 그 전에 화면을 떠나거나 탭을 숨기면 대기 타이머를 취소한다.

말풍선은 짧게 등장하고 기존 문의 버튼에 라임 테두리와 최대 두 번의 작은 들썩임을 준다. 4.4초 후 강조 상태를 종료하며, 화면 이탈·모션 중지 시에는 바로 종료해 돌아왔을 때 다시 시작하지 않는다. 움직임 감소·MOTION OFF에서는 정적으로 표시한다. 닫기 버튼은 44×44px이며 닫으면 기존 문의 링크로 포커스를 돌린다. 문서 WeakSet으로 같은 문서의 문의 페이지 왕복에서 안내를 새로 시작하지 않는다. 닫지 않고 다른 섹션만 다녀오면 기존 말풍선은 다시 보일 수 있다.

새 상담창이나 자동 전송은 추가하지 않았다. `/inquiry?from=film`의 기존 UI 미리보기로 연결하며 실제 전송·저장·업로드가 없는 상태를 보존한다. 말풍선·버튼은 공통 `SiteControls`에 한 번만 렌더링한다. 모바일 TOGETHER의 문의 아이콘을 영상 조작과 같은 하단에 배치하고, 짧은 화면은 말풍선 내부 여백을 줄여 본문과 겹치지 않게 했다.

## 검사와 저장 범위
