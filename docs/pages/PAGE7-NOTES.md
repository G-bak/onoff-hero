## 원본 분석과 적용

원본은 한 화면 크기의 배경 영상, 왼쪽·아래쪽 어두운 그라데이션, 왼쪽 아래 큰 영문 두 줄과 한국어 설명, 영상 재생·음소거 조작으로 구성했다. `onf-cinematic-intro.mp4`는 파란 빛의 ONF 로고와 입자가 등장하는 5초 영상이다. 원본의 `FROM START / TO RESULTS.`와 “처음부터 결과까지, 고객과 한 팀으로.”를 유지했다.

현재 사이트에서는 `SectionEntry`로 6페이지 다음에 연결하고 공통 측면 메뉴에 `07 FILM`을 추가했다. 전환 중에는 배경 영상이 먼저 재생되지만 링크·버튼의 `inert` 해제 시점은 공통 전환을 따른다. 새 헤더 메뉴를 중복으로 넣지 않았다. 7개 메뉴에서도 짧은 가로 화면의 상담톡이 메뉴를 가리지 않도록 배치했다.

제목은 아래에서 원근·압축을 풀며 약 1.15초에 걸쳐 등장하고 고정된다. `RESULTS.`는 #D8FF3E 중심의 라임 그라데이션과 라임·파란 발광, 한 번 지나가는 빛으로 강조한다. 반복적으로 흔들거나 반짝이지 않는다. 로컬 Montserrat/Pretendard를 사용한다. 데스크톱은 전면 영상, 세로 모바일은 로고를 위쪽에 두고 문구를 아래쪽에 배치한다. 낮은 가로 화면에는 별도 배치를 적용했다.

## 준비·재생 정책

- 기존 WEB의 `createWebFilmPlayback` 재사용: 실제 재생 이벤트와 프레임을 확인하고 자동재생 경합을 처리한다.
- 초기 고정 포스터·문구를 먼저 보여주지 않는다. 첫 실제 영상 프레임까지 전용 준비 UI를 표시하고 준비되면 등장한다. 임의 최소 지연은 없다.
- 기본은 무음 반복이며 소리는 사용자가 켠다. 화면 밖·가려짐·탭 숨김·MOTION OFF에서 멈춘다. 사용자가 직접 멈춘 상태는 페이지 재진입에도 유지한다.
- 자동재생 차단 시 명시적 재생 버튼, 네트워크 오류 시 재시도, 10초 이상 준비 지연 시 안내와 재시도를 제공한다.
- 움직임 감소에서는 정지 화면과 명시적 재생을 제공한다. MOTION OFF에서는 재생·재시도도 비활성화한다.
- JS 미사용에서는 준비 UI 없이 서버 문구·포스터·네이티브 영상 조작을 제공한다.
- VTT는 영상 속 화면 문구를 설명하며 음성 대본을 임의로 만들지 않았다. 소리·재생 버튼은 접근 가능한 한글 이름을 제공한다.

반응형 확인 크기는 1920×1080, 1440×900, 1280×720, 1024×768, 768×1024, 390×844, 320×568, 844×390, 568×320이다. 캡처는 `outputs/brand-film-*.png`. Chrome의 화면 크기 에뮬레이션과 소프트웨어 WebGL로 검사하며 실제 휴대폰 하드웨어 성능 검증으로 주장하지 않는다.

## 2026-09-13 제목 크기 후속 조정

사용자 요청으로 `FROM START / TO RESULTS.` 두 줄을 기존 크기의 92%로 줄였다. 화면별 기존 `clamp`, `vw`, `svh` 기준은 `--film-title-size`에 유지하고 공통 배율을 적용한다. 위치·등장 타이밍·RESULTS 발광·영상은 유지한다. 로컬만 반영했다.

브라우저 확인: 1440×900에서 128.16→117.907px, 1920×1080에서 170.88→157.21px, 390×844에서 40.56→37.3152px. 태블릿·가로 화면도 같은 0.92 비율을 유지한다. 고정 프로젝트 문의 링크 글자는 16px로 확인했고 기존 작은 화면의 아이콘 전용 표시 조건은 유지했다. 최종 `npm run ci:build` 통과.
