## 현재 카피

메인: **마케팅 전부, / 온앤오프 하나로**. 보조: **기획부터 제작·운영까지**, **다섯 분야를 한 번에**. 기획·디자인·웹사이트·마케팅·운영을 실무 범위로 설명한다. HTML과 로컬 Pretendard/Montserrat를 사용하며 가짜 성과 수치·직원 이름을 추가하지 않는다.

팀 인물은 2026-09-12 후속 요청으로 뒤돌기 8포즈씩, 총 40개 이미지를 다시 생성했다. 한 발 들기·무릎 굽힘·체중 이동·반대발 따라 딛기를 추가하고, 프레임마다 키를 강제로 맞추던 정렬을 끝점 기준으로 바꿔 몸의 높낮이를 보존한다. 기존 팔 올리기와 손목 X의 8포즈는 유지해 각 인물은 총 16포즈다. 정면 대기는 0.18초이며 다섯 명 모두 같은 시간표로 약 1.37초에 각자의 최종 뒷모습에 도달한 뒤 멈춘다. [인물 이미지·재생 기록](../../design/galaxy-crew/README.md).

## 최신 그래픽 변경

- 은하 전체를 한 장에 그려 확대하던 평면·텍스처와 워프 흰 선, 미리 그린 닫힌 궤도를 삭제했다.
- 은하 별은 각각 체적이 있는 8면체 인스턴스다. 목적지·시작 깊이·등장 시점·크기·색·회전 경로를 개별 속성으로 저장한다. 공통 형상을 GPU 인스턴싱으로 공유하고, 위치와 모션은 별마다 계산한다.
- 별 무리가 입체 공간에서 드러나 각자 나선 경로로 펼쳐진다. 카메라 접근은 이 흐름을 보조한다. 은하 그룹의 scale을 바꾸는 연출은 없다.
- 성운·먼지층도 개별 좌표와 경로를 가진 작은 스프라이트다. 128px 절차적 노이즈 질감 한 장은 작은 구름의 재료이며 은하 전체 이미지가 아니다. 별은 이 스프라이트 방식이 아닌 실제 입체 형상이다.
- 따뜻한 중심부·차가운 나선 팔·어두운 먼지 틈·희박한 분홍 가스층을 구성했다. 관측 자료에서 시각적 특징을 참고한 그래픽이며 천체 물리 시뮬레이션은 아니다.
- 정거장과 셔틀·비행선·로켓·탐사선·화물선은 서로 다른 실제 메시다. 비행체는 이전 크기에서 축소하고 엔진 불빛도 짧게 줄였다.
- 비행체는 각 궤도 위치에서 0.42초 동안 약 5% 오버슈트의 작은 팝으로 등장한다. 위에서 내려오는 이동은 없다.
- 비행체가 실제 지나간 구간에만 짧은 푸른 잔광을 만든다. 약 0.85 월드 단위 길이의 샘플 기록이며 꼬리 쪽 밝기가 연속적으로 줄어든다. 등장 이전의 경로는 그리지 않는다.

## 시간과 반응형

아래 시간은 장면 내부 시간이다. 2026-09-12 최신 요청으로 초반 재생 속도를 1.4배에서 1.75배로 올리고, 완성 직전에는 원래 공전 속도 1.4배로 연속 전환한다. 실제 인물은 약 2.69–3.0초에 등장하고 전체 서비스는 약 3.75초에 완성된다. 인물은 타이틀의 마지막 펼침과 겹쳐 등장하며 제스처 1.37초는 실제 시간으로 따로 유지한다. 내부 비행체 합류 시점과 별의 개별 경로는 그대로다.

- 0–0.6초: 먼 별만 보이는 우주. 은하와 비행체는 보이지 않는다.
- 0–2.9초: 원근 카메라가 최종 거리의 2.3배에서 접근한다. 고정 40도 화각이며 과장된 워프 선은 없다.
- 0.6–4.2초: 별마다 다른 깊이와 시간으로 출발해 나선 은하에 자리 잡는다. 구름의 밝기는 조금 늦게 따라온다.
- 2.85초부터: 작은 정거장이 제자리에서 등장한다.
- 3.05초부터: 다섯 비행체가 0.16초 간격으로 제자리에서 등장한 뒤 부드럽게 가속한다. 팝·공전·잔광은 같은 합류 시각을 공유한다.
- 3.8–5.2초: 제목과 통합 메시지. 은하는 오른쪽에 자리 잡는다.
- 4.4–6.42초: 다섯 서비스 순차 등장.
- 4.7–5.25초: 다섯 인물·하단 표기가 타이틀 마지막 부분과 겹쳐 함께 등장한다. 이후에도 은하 회전·공전은 이어진다.
- 인물 등장·이미지 디코딩이 완료되고 인물 영역이 실제로 보이면 제스처를 정면부터 한 번 재생한다. 마지막 뒷모습에서 계속 멈추며 GIF도 loop=1로 내보낸다.

데스크톱 최소 높이 800px, 1100px 이하 1240px, 600px 이하 1280px. 좁은 화면에서는 제목·은하·서비스 격자·팀 순서다. 전체 페이지 종횡비를 고정하지 않는다.

## 수명·품질·대체 화면

면 전환 48% 이후 진입을 시작한다. #why에서 직접 새로고침할 때는 공통 로더의 최소 대기를 1000ms에서 0ms로, 종료 페이드를 500ms에서 180ms로 줄였다. 실제 준비 완료 확인은 생략하지 않으며 첫 3D 렌더 전에는 섹션 로딩 UI를 유지한다. 다른 진입 주소는 기존 공통 로더 시간을 사용한다. HOME으로 돌아오면 전체 진입을 초기화한다. DESIGN 등 다음 페이지에 가려지면 인물 제스처를 최종 뒷모습으로 유지한다. SYSTEM으로 돌아올 때 은하는 조립된 상태를 이어가고 인물만 따로 재생하지 않는다. 모바일에서 인물 영역을 벗어나는 경우에도 제스처를 초기화하지 않는다. 숨긴 탭·뷰포트 밖·초기 main 잠금 동안 프레임을 예약하지 않는다. 인물도 같은 시간에 멈춘다. 제스처는 부모 CSS 변수 한 개로 다섯 명의 프레임을 동시에 바꾼다. 탭을 숨기거나 MOTION OFF로 바꾸면 현재 자세를 유지하고, 움직임 감소는 최종 뒷모습을 표시한다. 이미지가 늦거나 디코딩에 실패해도 기존 다섯 인물을 유지한다.

MOTION OFF·움직임 감소는 완성된 정지 장면을 표시한다. WebGL 손실 시 기존 자원을 정리하고 SVG/HTML을 표시하며 복원 시 새 GPU 자원을 만든다. JavaScript 없이도 카피·서비스·인물을 읽을 수 있다. 대체 화면에도 미리 그린 궤도는 없다.

큰 화면: 입체 별 32,000개, 구름 3,600개, 먼지 1,200개. 작은 화면: 14,000 / 1,800 / 600개. 먼 배경 별 1,400개는 작은 포인트다. 버퍼 상한 약 165만/95만 픽셀이며 작은 화면은 bloom을 생략한다. 형상·재질·버퍼는 재사용하고 프레임마다 새로 만들지 않는다. 외부 런타임 이미지·영상·글꼴 요청이나 새 라이브러리를 추가하지 않았다.

## 검증

초기 은하 버전 결과는 Git에서 제외되는 outputs/qa/2026-09-11/system/galaxy-v3-*에 기록한다. 아래 과거 검증은 당시 버전의 이력이다. 실제 진입 영상은 outputs/qa/2026-09-11/system/galaxy-v3-entry.webm이다. 이전 galaxy-entry.webm은 과거 버전이므로 이번 결과로 제공하지 않는다.

최종 npm run ci:build 통과: 린트·타입·단위 검사 50개·프로덕션 빌드·CSS/글꼴/자산 검사. 1440×900, 2048×1020, 390×844, 320×740, 768×1024, 844×390에서 경계·글자·인물을 검사했고 가로 넘침은 없었다. 브라우저 13개 시나리오(부분 진입 대기·단계 순서·공전·인물 모션·숨긴 탭·WebGL 손실/복원·CARD 가림·HOME 재생·공통 상담·MOTION OFF·움직임 감소·JavaScript 없음·WebGL 없음)가 통과했다. 강제로 WebGL을 차단한 시나리오의 예상 오류 외에 예기치 않은 콘솔/페이지 오류는 없었다. 브라우저 검증은 Chrome 소프트웨어 WebGL 환경이며 실제 휴대폰의 FPS 측정으로 해석하지 않는다.


이전 8포즈 버전 검증(2026-09-12): 새 8포즈 시간표를 포함한 단위 검사 53개와 ci:build 통과. 한 주기 동안 다섯 명의 x 프레임이 매 샘플 동일했고 8개 포즈를 모두 표시했다. 6개 반응형 크기와 기존 브라우저 13개 시나리오가 통과했다. 최종 자료는 outputs/qa/2026-09-12/system/galaxy-crew-ci.log, outputs/qa/2026-09-12/system/galaxy-crew-browser.json, outputs/qa/2026-09-12/system/galaxy-crew-probe.log. 당시 GIF 공개 주소는 `/images/galaxy-crew/team-salute.gif`였다. 현재는 [보관 GIF](../../design/archive/public/images/galaxy-crew/team-salute.gif)로 확인한다.

이미지 지연·실패 추가 검사도 통과했다. 이미지 응답을 진입 완료까지 지연해도 기존 다섯 인물이 유지되고, 준비 후 다섯 명 모두 정면부터 시작했다. 강제로 디코딩에 실패하게 해도 기존 인물과 은하를 유지했으며 페이지 오류는 없었다. 결과는 outputs/qa/2026-09-12/system/crew-asset-browser.json, 모바일 녹화는 outputs/qa/2026-09-12/system/crew-mobile.webm, 최종 자세는 outputs/qa/2026-09-12/system/crew-salute-mobile.png다.

최신 16포즈·1회 재생 검증(2026-09-12): npm run ci:build의 린트·타입·53개 단위 검사·프로덕션 빌드·자산 검사를 통과했다. 전체 16포즈 동기화, 완료 후 자세 유지, HOME/CARD 양방향 재진입, 숨긴 탭에서 중간 자세 일시 정지, 모바일에서 실제 보일 때 시작, 움직임 감소의 최종 자세를 브라우저에서 확인했다. 기존 은하·면 전환·상담·WebGL 복구 등 13개 시나리오, 6개 반응형 크기, 느린 이미지 응답과 디코딩 실패 검사도 통과했다. 새 검사에서 예기치 않은 페이지/콘솔 오류는 없었다. 자료는 outputs/qa/2026-09-12/system/crew-v2-ci.log, crew-v2-browser.json, galaxy-v4-browser.json, crew-v2-asset-browser.json, crew-v2-probe.log이며 동작 녹화는 outputs/qa/2026-09-12/system/crew-v2-desktop.webm이다. 로컬에만 반영했고 배포하지 않았다.
