# HOME 3D 오프닝 — 2026-09-13

## 요청과 현재 구현

새 문서의 홈페이지 첫 진입에서 ON&OFF 글자가 화면 밖에서 개별로 튀어 들어오고, `&`가 위에서 떨어져 주변 글자의 간격과 기울기가 정렬된다. 정렬된 로고를 잠시 보여준 뒤 기존 HOME 워드마크 위치에 안착시킨다. 도킹 후반과 겹쳐 앞·뒤 3D 카드가 함께 위에서 내려오고 헤더·본문·하단 조작이 순차 등장한다. 전체를 1.5배 재생하여 실제 카드 준비 이후 연출 시간은 약 5.8초다. `openingPlaybackRate`를 공통 장면 시계에 적용하며 코드의 시간표는 기존 8.7 장면초 기준이다. 소리와 새 영상 파일은 추가하지 않았다.

최신 이징은 뾰족하고 빠른 도약을 둥근 산 모양으로 완화한 상태다. 높이는 코사인 기반 곡선으로 시작·중간 정점·착지의 수직 속도가0이며, 가로 이동은 `cubic-bezier(.36,0,.64,1)`의 완만한 가속·감속이다. 첫 두 도약의 가로 초과 이동은1.8%에서0.8%로 줄이고 도약 후반에만 적용한다. 회전도 둥근 곡선을 약간 늦게 따라가며 착지 시 속도까지0으로 멎는다. 준비 압축·작아지는 네 번의 도약·최종 정렬을 유지한다. `&`의 낙하 시간은 최신 요청으로0.72→0.48초(1.5배속)이며 초기 낙하는 3차 Ease In으로 천천히 출발해 착지할수록 빨라지며 착지 후 반동은 둥근 곡선이다. 도킹·카드·본문의 Ease Out은 `cubic-bezier(.16,1,.3,1)`이며 0–1 범위와 정확한 끝점을 유지한다.

## 참고와 독자 제작 범위

사용자 참고: [Spline Logo animation / victory](https://community.spline.design/file/5a629003-1737-4b1c-a9f0-6ff885e3c1e2). 공개 제목·설명·path/text/logo/fluid/glass 분류와 미리보기 접근을 확인했다. 이번 확인 환경에서는 Spline 미리보기의 WebGPU 파이프라인 오류로 실제 모션 재생을 확인하지 못했다. 따라서 원본의 움직임·재질·시간표를 관찰·복제했다고 주장하지 않는다. 유료 다운로드·Remix·원본 코드·3D 모델·Spline 런타임을 사용하지 않았다.

전문 모션 참고는 제작사 공식 소개인 [DIA Squarespace](https://dia.tv/project/squarespace/), [Studio Dumbar Utah Jazz 50](https://studiodumbar.com/work/utah-jazz-50), [DIA CATK](https://dia.tv/project/catk/)다. 타이포그래피의 일관된 움직임 규칙, 글자별 리듬과 재질 차이, 사이트 콘텐츠로 이어지는 아이덴티티라는 방향을 참고했다. 위 시간표와 낙하·정렬·카드 연결은 ON&OFF 요청에 맞춰 작성한 연출이다. 참고 사이트의 이미지·영상·코드를 서비스 자산으로 가져오지 않았다.

## 소스와 글꼴

- `lib/home-opening.ts`: 진입 정책, 글자별 포즈, 카드의 연속 속도 곡선, 전체 시간표.
- `lib/opening-scene.ts`: 기존 Three.js로 4개 윤곽을 돌출한 geometry, O/F를 공유하는 6개 실제 3D mesh, 조명·그림자·환경맵.
- `app/components/hero-opening.tsx`: 자산 준비·프레임 예약·탭 가시성·건너뛰기·오류·자원 정리.
- `app/components/scene-loader.tsx`: 기존 카드의 실제 준비 신호와 연결. 스크롤 잠금과 `main.inert` 해제 시점을 분리한다.
- `app/components/wordmark.tsx`, `app/home-opening.css`: 기존 글꼴·색상·반응형 크기·문구를 유지하며 글자별 측정점과 입장 표시를 제공한다.
- `scripts/prepare-opening-font.mjs`: 설치된 Montserrat Latin Bold 700 WOFF의 O/N/&/F 원본 윤곽을 `app/assets/opening/montserrat-bold.json`으로 결정적으로 추출한다. 수동 실행 `node scripts/prepare-opening-font.mjs`.

폰트는 기존 홈페이지의 Montserrat 700과 같은 원본이다. [Montserrat 라이선스](../../public/fonts/MONTSERRAT-LICENSE.txt)를 보존한다. 원본 SHA-256은 `ff51c769e51acaa5ffbb8091441ff4e365e41ff21f7e4c05d1cd5650514d6fd3`, 윤곽 JSON은 5,832바이트다. 생성 JSON은 실행 자산으로 저장소 관리 대상이며 라이브러리·유료 플러그인·Blender 작업 파일을 추가하지 않았다.

도킹은 고정 픽셀 좌표 대신 준비된 실제 DOM의 글자별 Range, 0크기 baseline marker, 계산된 font-size를 읽는다. 글자 외곽을 바꾸는 bevel은 사용하지 않는다. 앞면 Z=0, 깊이는 뒤로 0.16em이며 정착 직전 환경·직접 조명은 0, 앞면 발광 색상은 원래 글자색으로 수렴한다. 최종 HTML 전환은 140ms 이내의 짧은 교차 표시다. 후속 [브라우저 QA](../reviews/HOME-OPENING-QA-2026-09-13.md)에서 PC 글자 외곽 차이 최대 1px, 모바일 경계 일치를 확인했다. DOM 힌팅과 WebGL 안티앨리어싱은 달라 픽셀 전체가 동일하지는 않다.

## 진입·접근성·복구 정책

- 새 문서 `/` 또는 맨 위 `/#home`에서 한 번 재생한다. 일반 새로고침도 새 문서이므로 재생한다. 복원된 스크롤 위치가 있으면 도입을 생략한다.
- 같은 문서의 상세·문의 → 홈 이동, 브라우저 뒤로가기, 직접 `#why` 등 다른 섹션 주소는 오프닝을 반복하지 않는다. 문서 단위 WeakSet이며 영구 저장소나 세션 타이머를 쓰지 않는다.
- 움직임 감소 설정에서는 오프닝을 생략한다. 재생 중 설정이 바뀌어도 즉시 종료한다. 건너뛰기 버튼·Escape 키를 제공하고 건너뛴 뒤 홈에 스크롤 이동 없이 포커스를 돌린다.
- 카드 앞·뒤의 실제 첫 렌더 준비 전에는 기존 준비 UI를 유지한다. 오프닝만의 글꼴·모듈 준비 실패·8초 초기화 제한·WebGL 손실은 오프닝만 종료한다. 카드의 기존 오류·기본 화면·최대 대기 안내를 보존한다.
- 카드만 오프닝 동안 일시 정지한다. 전역 MOTION 상태와 2–7페이지의 재생 정책은 변경하지 않는다. 기존 카드 높이·워드마크 위치·색·회전 방향·수동 조작을 보존한다.
- 두 카드 레이어에 독립 `translate`를 동일하게 적용해 기존 `transform`과 3D 버퍼 크기를 보존한다. 화면을 숨기려고 레이아웃 크기를 0으로 만들지 않는다.
- 숨겨진 탭에서는 프레임과 장면 시간이 멈춘다. 도킹 후 오프닝 WebGL을 먼저 해제해도 남은 UI 등장 시간은 재개된다. 완료·건너뛰기·실패·언마운트는 자원·이벤트·CSS 변수를 정리한다.
- 페이지 완료 시 강제 `scrollTo(0)`를 추가하지 않는다. JS 미사용 시 오프닝 canvas를 만들지 않고 기존 HTML·기본 카드·일반 섹션 흐름을 제공한다.
