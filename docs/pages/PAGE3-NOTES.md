2026-09-13 최신 스크롤 조정: 작업물이 너무 빨리 넘어간다는 요청으로 추가 감상 구간을 100svh에서 125svh로 늘렸다. 작업물별 스크롤 길이는 25% 증가한다. 1440×900에서 DESIGN 전체 높이는 1800→2025px, 작업물별 길이는 300→375px이며 WEB 앵커는 3600→3825px다. 페이지 배치·이미지 등장·공통 면 전환 거리·휠/터치 정책은 유지한다. 아래 150→100svh 단축 설명은 이전 요청의 이력이다.

PC 1440×900·모바일 390×844 브라우저에서 앞뒤 스크롤의 세 작업물 선택, 썸네일 선택과 스크롤 위치 동기화, WEB 진입·DESIGN 복귀를 확인했다. 모바일 감상 구간은 1055px이며 실제 휠로 선택이 순차 전환된다. WEB의 부모 inert가 해제되고 직접 앵커가 맞는 것을 확인했다. 움직임 감소는 추가 여백 없이 높이844px의 일반 지면을 유지한다. 기존 섹션 전환 테스트11개를 통과했다. 로컬 저장만 완료했으며 커밋·push·배포하지 않았다.

이전 사용자 요청: 인물을 3페이지가 드러날 때부터 보여주고, 국내 사례를 조사해 와닿는 문구와 고객 목적에 맞는 포트폴리오 이미지로 교체하며, 스크롤을 조금 줄일 것. 앞서 승인된 고유한 편집 지면은 유지한다. 로컬 주소 http://localhost:5187/#design. 커밋·push·배포하지 않는다.

## 현재 구성

따뜻한 종이색 #F0F0E9 배경, 검정 #090A0F 글자, 라임 #D8FF3E 인덱스와 인쇄 여백. 데스크톱은 왼쪽 DE↗ / SIGN 분할 제목·짧은 문구·썸네일 목차, 오른쪽은 크게 보는 작업물 한 장의 비대칭 편집 지면이다. Montserrat700과 Pretendard Variable의 로컬 글꼴을 보존한다. 문구는 **눈길을 사로잡고 / 구매로 이어지게**, 영문 보조는 DESIGN THAT SELLS다. 국내 서비스 사례를 참고해 고객의 관심과 구매라는 목적을 직접 전달하도록 작성했다. 조사 출처·타깃 가설·이미지 전문 프롬프트는 [v2 자산 기록](../../design/design-showcase/v2/README.md)에 있다. 발행 정보·가는 구분선·작업물 번호로 잡지 스타일을 구성한다.

스크롤하면 F&B 모닝오븐 → BEAUTY 온결 → LIVING 루움 순서로 바뀌며 역방향도 같은 위치를 따른다. 각 이미지의 다섯 세로 구획이75ms 간격으로 위로 드러나는 인쇄 모션이다. 앞 작업물을 뒤에 보존하므로 교체 중 빈 화면이 생기지 않는다. 단일 지면은 스크롤·포인터에 따라 작은 원근 각도로 변한다. 이 장면은 HTML과 CSS3D이며 별도의 WebGL 장면을 만들지 않는다. 실제3D 모델링이라고 보고하지 않는다.

추가 감상 구간을150svh에서100svh로 줄였다.1440×900 기준 전체 DESIGN은2250→1800px로20% 짧아졌다. 인물의 opacity0 진입 효과가 앞면 전환의 inert 잠금에 걸려 늦게 나오던 문제는 별도 인물 등장 효과를 제거하고 DESIGN의 장식 인물만 전환 중 재생하도록 해결했다. main의 초기 로딩 잠금은 예외가 아니며, 페이지 조작의 inert는 그대로다. 인물의 원본·춤 포즈·속도는 보존한다.

썸네일 세 개와 NEXT는 실제 작업물 선택 버튼이다. native scroll 위치와 동기화하며 휠·터치를 가로채지 않는다. 키보드 Enter/Space와 aria-pressed를 지원한다. 움직임 감소에서는 스크롤 이동·출력 모션·원근을 생략하고 선택만 바꾼다. 페이지 전체 비율은 고정하지 않고 이미지의4:5만 유지한다. 모바일은 제목→큰 작업물→목차 순서다. 지면 크기는 실제 이미지 영역의 폭·높이에 맞추며 사진 설명과 목차·하단·상담 버튼이 겹치지 않게 조정한다.

- app/page.tsx: 기존 다섯 페이지 순서와 네 개의 SectionEntry는 유지하고 DESIGN만 새 컴포넌트로 교체한다.
- app/components/card-showcase.tsx와 lib/card-showcase.ts는 다시 마케팅 전용이다. category=design 분기·이미지 import·designPanels·기존 디자인 모델 테스트·관련 CSS를 제거했다. 5페이지의 광고·실제 영상·마케터 자산과 동작은 보존한다.
- app/creative-sections.css는 공통 메뉴 테마를 담당한다. WEB 상세 스타일은 app/web-cinema.css로 분리했다.3페이지의 이전 스타일은 제거했다.
- lib/scene-frame-loop.ts의 기존 예약/정착 함수를 재사용한다. 포인터·스크롤 보간이 끝나면 RAF를 멈춘다. 숨긴 탭·다른 면에 가려짐·뷰포트 밖·초기 로더 잠금·MOTION OFF 동안 동작을 멈춘다. CSS animation-play-state도 함께 제어한다.
- JavaScript 미사용 시 원본 이미지와 썸네일은 남는다. 이미지 실패 시 해당 작업물 이름과 안내를 표시한다.

이미지는 내장 ImageGen으로 새로 생성한 모닝오븐(메뉴 포스터·포장), 온결(뷰티 패키지·제형 콘텐츠), 루움(침구 사용 장면·소재 디테일)이다.720×900 WebP3장 합계267,820B이며 한 배치에서 이미지별 한 번씩 생성했다. 실제 고객 사례가 아닌 가상 브랜드임을 화면에 표시한다. 최신 인물은 최초 카드 원본을 직접 참조한 실제8포즈다. 긴 셔츠·넓은 바지·회색 운동화를 유지하고 받침대를 제거했다. 뒷사선에서 팔꿈치를 굽히며 양손을 올렸다 내리는1120ms 왕복 춤이며, 손을 머리 가까이 당기는0~1번만 제외하고 팔을 내리는2·3번을 복원해2~7번을 재생한다. 5페이지처럼 포즈별 시간표를 사용한다. 광학 흐름·MCI·몸의 CSS 회전은 없다. 인물은 제목의 잘리는 영역 밖에 있다. [현재 인물 원본·프롬프트·검토](../../design/people-motion/v4/README.md). 승인된 지면과 작업물 모션은 유지한다. CSS 출력 구획·대표 이미지·썸네일은 같은 해시 URL을 공유한다. 이미지의 원본·프롬프트는 design/design-showcase/v2/README.md, 이전 화면 기록은 HISTORY-three-panel-layout.md다.
