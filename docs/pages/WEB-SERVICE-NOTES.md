## 구현과 검증 기준

- 전용 서버 컴포넌트 `web-service-detail.tsx`, 전용 스타일 `web-service.css`, 내용/가격 유형/출처 데이터 `lib/web-service.ts`. 공유 목록의 웹 메타데이터와 가격 설명도 맞췄다.
- 기존 `ServiceDetailMotion`의 이미지·글꼴 준비 UI, 장별 등장, 읽기 진행선, 활성 목차, 탭 숨김·움직임 감소·noscript 처리를 재사용한다. 새로운 WebGL이나 강제 스크롤·고정 스크롤 구간은 없다.
