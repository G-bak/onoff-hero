# 날짜별 작업 일지

슬랙 공유용 일일 작업 보고서를 날짜별 폴더로 관리한다.

- 저장 위치: `docs/daily-work/YYYY-MM-DD/WORK-LOG.md`
- 날짜 기준: 한국시간(KST)의 실제 작업일.
- 같은 날의 후속 작업은 해당 날짜 파일에 추가하고, 다음 날은 새 날짜 폴더를 만든다.
- 작업 결과·운영 배포 완료·로컬 수정 상태·남은 작업을 구분한다.
- 배포 시각은 실제 성공 기록을 기준으로 적고, 검색 색인이나 외부 서비스 처리를 확인 없이 완료로 쓰지 않는다.
- 슬랙에 파일 첨부하거나 내용을 복사하기 쉽게 작성한다. 비밀값·계정 식별자·긴 검증 로그는 넣지 않는다.
