# ON&OFF 홈페이지 작업 보고 — 2026.09.18

SEO 설정, 공유용 OG 이미지, 마케팅 카드 이미지 교체를 운영 사이트에 배포했습니다. 이후 요청된 메인·OG의 ‘고객님은’ 변경과 내부 이동 주소의 해시 제거는 수정·검증을 완료했으며, 사용자 요청으로 함께 운영 배포를 진행합니다.

## 1. 페이지별 SEO 정비 — 배포 완료

- 메인·마케팅·웹·디자인 페이지의 검색 제목(title)과 설명(description)을 요청한 문구로 변경했습니다.
- 마케팅은 ‘평택 광고대행사’, 웹은 ‘평택 웹디자인·홈페이지 제작’, 디자인은 ‘평택 로고디자인·디자인’을 중심으로 메타데이터를 정리했습니다.
- 기획·운영·문의 페이지의 고유 제목과 설명을 유지하고, 공개 7개 페이지의 제목·설명이 서로 중복되지 않는지 확인했습니다.
- Open Graph와 X/Twitter의 제목·설명도 각 페이지와 일치하도록 반영했습니다.
- 마케팅·웹·디자인의 기존 본문 설명에 관련 지역 키워드를 각각 1회 자연스럽게 추가했습니다.
- 실제 페이지 주소를 가리키는 canonical, 기존 네이버 인증 태그, robots.txt, sitemap.xml을 유지했습니다.
- 검색엔진의 재수집·색인·검색 순위 반영 완료를 의미하지는 않습니다.

## 2. 공유용 OG 이미지 적용 — 배포 완료

- 사용자가 제공한 ON&OFF 이미지(1200×630)를 사이트 공통 공유 이미지로 적용했습니다.
- 메인·서비스 상세 5개·문의, 총 7개 페이지에 OG 및 X/Twitter 이미지 연결을 완료했습니다.
- 운영 이미지 응답과 원본 파일 일치 여부를 확인했습니다.
- 아래 4번의 호칭 수정 전 이미지가 현재 운영에 반영된 버전입니다. 실제 메신저 미리보기의 캐시 갱신 여부는 별도 확인이 필요합니다.

## 3. 마케팅 상세 카드 이미지 3장 교체 — 배포 완료

- SNS: LUMET 뷰티 디바이스 이미지.
- 블로그: NOURVE 영양제 콘텐츠 이미지.
- 캠페인: PLOOP 음료 캠페인 이미지.
- 제공된 720×1460 원본을 무손실 WebP로 변환해 적용했습니다.
- 세 카드의 동일한 프레임 크기와 이미지 비율 유지, 기존 반응형 구성을 보존했습니다.
- 블로그 분류를 ‘HEALTH / BLOG’로 맞추고 이미지 대체 설명도 새 내용으로 변경했습니다.

## 4. 메인·OG 호칭 통일 — 수정 완료, 배포 진행

- 메인 문구를 ‘당신은 사업만 ON’에서 ‘고객님은 사업만 ON’으로 변경했습니다.
- 공통 OG/X 이미지 대체 설명과 OG 이미지 안의 문구도 같은 호칭으로 수정했습니다.
- 현재 사이트 텍스트에 같은 이전 표현이 더 남아 있는지 확인했습니다.
- 기존 화면의 글꼴·줄바꿈·ON/OFF 강조·반응형 설정과 애니메이션을 유지했습니다.
- OG 이미지는 기존 시안을 기준으로 문구를 편집하고 1200×630 규격으로 적용했습니다.
- 마케팅 이미지 스타일 재작업 요청은 취소되어, 3번에서 배포한 카드 이미지를 유지했습니다.

## 5. 내부 이동 주소의 해시 제거 — 수정 완료, 배포 진행

- 상세페이지 좌측 로고를 눌렀을 때 `/#home`이 붙던 링크를 `/`로 변경했습니다.
- 상세 5개의 로고·서비스 목록·푸터, 문의 페이지의 홈 복귀, 메인 메뉴와 각 페이지 목차까지 내부 이동 링크를 모두 정리했습니다.
- 주소와 이동할 섹션을 분리해, 해시 없이 기존 위치 이동을 유지하도록 수정했습니다.
- 이전 해시 주소로 들어오는 경우와 로딩 중 이동, 뒤로가기·키보드 이동을 검사했습니다.
- 공개 7개 페이지의 내부 링크 157개에서 해시가 없으며, 섹션 이동 링크 87개의 대상이 연결돼 있음을 확인했습니다.

- 각 수정본의 기존 검사·린트·타입 검사·프로덕션 빌드·CSS/자산 검사를 통과했습니다.
- 배포 후 공개 7개 페이지의 정상 응답, SEO/OG 설정, 이미지 파일과 문의 접수 활성 상태를 확인했습니다.
- 최신 로컬 수정도 7개 페이지의 정상 응답과 문구 변경을 확인했으며, 요청한 부분 외 본문·SEO·CSS 참조가 동일함을 검증했습니다.
