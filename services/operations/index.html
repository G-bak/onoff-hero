02 / WHAT WE DO

어떤 작업이
필요하세요?

문구·사진을 바꾸는 일부터 새 페이지 제작까지. 작업별 예시와 진행 방식을 확인해 보세요.

이미 있는 내용을 바꾸고 싶어요

지금 쓰는 홈페이지나 홍보물의 내용을 바꾸거나, 화면과 링크에 문제가 없는지 확인하는 작업입니다.

회사·상품 정보 수정

“주소가 바뀌었어요. 가격도 수정해 주세요.”

기존 화면의 주소, 연락처, 상품 설명처럼 달라진 정보를 반영합니다.

사진·배너 교체

“이 사진을 새 제품 사진으로 바꾸고 싶어요.”

현재 위치와 크기에 맞춰 이미지를 교체합니다. 새 이미지 제작이 필요하면 먼저 안내합니다.

화면·링크 점검

“버튼을 눌렀는데 페이지가 안 열려요.”

확인하기로 한 화면과 링크, 문의 경로를 점검하고 문제와 필요한 조치를 알려드립니다.

월 관리 또는 건별 작업으로 진행해요

월 관리를 이용 중이라면 계약에 포함된 작업인지 먼저 확인합니다. 포함되지 않은 작업이나 한 번만 필요한 수정은 비용과 일정을 안내한 뒤 진행합니다.

요청할 때 이렇게 알려주세요

현재 페이지 주소와 바꿀 위치, 새 문구·사진을 보내주세요. 문제가 생겼다면 어떤 상황에서 발생했는지도 알려주세요.

어느 쪽인지 몰라도 괜찮습니다. 바꾸고 싶은 내용을 보내주시면 필요한 작업부터 구분해 드립니다.
작업을 마치면 변경 내역과 확인할 내용을 함께 전달합니다.

03 / HOW WE WORK

진행은 명확하게,
확인은 단계마다

처음 정한 범위와 일정을 기준으로 진행하며,
각 단계에서 함께 확인할 내용을 안내합니다.

  1. 01

    수정 내용 전달

    페이지 주소와 변경할 위치, 새 문구·사진을 전달해 주세요. 오류는 발생 화면과 상황을 함께 알려주시면 확인에 도움이 됩니다.

    준비할 것 / 주소·변경 내용·자료
  2. 02

    범위·일정 안내

    월 관리 포함 작업인지 별도 작업인지 확인하고 처리 일정과 필요한 자료를 안내합니다.

    확인할 것 / 포함 여부·비용·일정
  3. 03

    작업·화면 점검

    합의한 내용을 반영하고 변경된 화면과 연결 부분을 확인합니다. 공개 시점이 필요한 경우 먼저 맞춥니다.

    함께 볼 것 / 반영 화면·점검 내용
  4. 04

    검수·내역 정리

    완료한 변경 사항을 전달하고 확인을 받습니다. 추가로 필요한 개선은 다음 작업으로 구분해 정리합니다.

    받으실 것 / 처리 내역·확인 사항

05 / FAQ

문의 전에
확인해 보세요

다른 업체에서 만든 홈페이지도 관리할 수 있나요?+

제작 방식, 소스와 계정 접근 권한, 현재 운영 환경을 먼저 확인해야 합니다. 확인 후 가능한 작업과 제한 사항을 안내하며, 모든 외부 사이트의 관리를 바로 확약하지는 않습니다.

월 관리에 수정이 무제한 포함되나요?+

무제한 상품이 아닙니다. 월 포함 작업량, 요청 한 건의 기준, 수정 난이도와 초과 작업 비용을 계약 전에 정합니다. 새 페이지나 새 기능은 별도 제작으로 구분합니다.

급한 오류는 바로 처리되나요?+

긴급 대응 가능 여부와 연락 방법, 업무 시간, 접수·처리 기준은 계약 전에 협의합니다. 장애 원인과 외부 서비스 상태에 따라 필요한 작업이 달라지므로 24시간 대응이나 즉시 복구를 일괄 약속하지 않습니다.

무료 오류 수정과 유료 변경은 어떻게 다른가요?+

납품한 범위에서 발생한 오류와 새 원고·사진 교체, 기능 추가 같은 변경 요청을 구분합니다. 오류 지원 기간과 제외 항목, 운영 중 변경 비용은 계약한 내용을 기준으로 확인합니다.
