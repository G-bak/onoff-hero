05 / FAQ

문의 전에
많이 궁금해하시는 것들

스타터와 기업 홈페이지는 무엇이 다른가요?+

기획을 누가 담당하는지가 다릅니다. 스타터는 고객사가 메뉴 구조와 페이지별 구성안을 준비하고, 온앤오프가 디자인·개발합니다. 기업은 온앤오프가 사업과 콘텐츠를 바탕으로 구성안을 작성해 고객 확인을 받습니다. 기획 외 기본 제작 범위는 같으며, 기업에 더 많은 페이지나 별도의 고급 기능이 자동으로 포함되지는 않습니다.

기획이나 글·사진이 없어도 문의할 수 있나요?+

평택 홈페이지 제작을 문의하실 때는 현재 가진 자료와 소개하려는 사업부터 알려주세요. 메뉴와 페이지 기획부터 필요하다면 기업 패키지로 안내합니다. 고객이 제공할 자료와 새로 제작할 자료를 구분하며, 전체 원고 작성·촬영·영상·로고 제작은 별도 범위로 협의합니다.

게시판과 일반 문의폼은 기본으로 제공되나요?+

일반 문의폼은 세 패키지 모두 포함하며, 승인한 입력 항목과 동의 문구를 적용해 지정 이메일로 문의를 전달합니다. 게시판의 목록·상세 화면과 초기 게시물 등록은 모두 추가 옵션입니다. 일반 문의폼에는 파일 업로드나 문의 처리 상태 관리가 포함되지 않습니다.

제작 기간과 수정 범위는 어떻게 정하나요?+

페이지·섹션 수, 기능과 자료 준비 상태를 확인해 일정과 수정 횟수를 견적서에서 확정합니다. 제작 중 수정은 승인한 방향 안의 문구·사진·색상·간격 조정이 기준이며, 새 페이지·구조 변경·새 디자인 방향은 별도로 협의합니다. 자료 전달과 고객 검토, 외부 서비스 처리에 필요한 기간도 함께 확인합니다.

오픈 후 콘텐츠는 직접 수정할 수 있나요?+

랜딩·스타터·기업 패키지는 고객용 편집 관리자 화면을 제공하지 않습니다. 문구·이미지·게시물·팝업 변경은 담당자에게 요청합니다. 월 관리에 가입하지 않아도 건별 지원을 이용할 수 있으며, 요청 범위와 비용을 확인한 뒤 진행합니다.

쇼핑몰이나 예약·결제 기능도 의뢰할 수 있나요?+

회원·쇼핑몰·예약·결제·업무시스템은 소개형 패키지와 구분해 비즈니스 개별 개발로 검토합니다. 필요한 사용자 역할과 기능, 실제 처리 방식, 외부 서비스 연결과 운영 규모를 확인한 뒤 가능한 범위와 개발비·일정·운영비를 제안합니다. 검토한 내용은 개별 견적과 계약에서 확정합니다.

제작 오류 수정과 유지보수는 어떻게 다른가요?+
